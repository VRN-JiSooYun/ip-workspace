# 합성 보드(Synthesis Board) 고도화 계획 v2

합성 보드 페이지를 기획서 사양에 맞춰 고도화하되, 데이터 소스 분리(Designs/Compounds) 및 단일 선택(Single Select) 구조로 최적화합니다.

## 1. 데이터 소스 관리 및 탭 구조 (NEW)

### 상단 토글 탭 (Segmented/Tabs)
- **My Designs**: 연구원이 직접 디자인한 합성 후보 물질 그룹 리스트 로드.
- **My Compounds**: 실제 합성되어 관리 중인 화합물 그룹 리스트 로드.
- 각 탭 선택 시 좌측 'Synthesis Group' 테이블의 데이터가 해당 소스에 맞춰 실시간으로 전환됩니다.

## 2. 테이블 구조 및 내용 개편

### 합성 그룹 리스트 (좌측 테이블) - **단일 선택(Single Select)**
- **동작**: 체크박스 대신 행 클릭 또는 라디오 버튼 형태의 단일 선택 구조 적용. 하나의 그룹만 집중하여 상세 정보를 확인할 수 있도록 최적화.
- **컬럼 구성**:
    - `Num`: 순번.
    - `Date`: 그룹 생성일.
    - `Type`: 그룹 타입.
    - `Target`: 타겟 단백질 정보.
    - `Title`: 그룹 명칭.
    - `공유`: 공유 상태.
    - `합성 중`: 진행률 카운트.
    - `합성 완료`: 합성 완료 카운트.
    - `미배정`: 미배정된 화합물 수.
    - `총개수`: 총 화합물 수.
    - `담당자N`: 담당자들에게 할당된 화합물의 수, 담당자가 N명 만큼 컬럼 늘어남(현재는 6명으로 하고, 추후에는 관리자 페이지에서 담당자 관리)

### 합성 상세 리스트 (우측 테이블)
- **컬럼 구성**:
    - `Num`: 순번.
    - `Grp.`: 화합물 관리 번호 (예: 1, 2, 3...). 
    - `Compound`: 화합물 명칭.
    - `Structure`: 2D 구조 이미지/아이콘.
    - `Name`: 화합물 이름.
    - `합성 담당자`: 담당자N (화합물 관리 테이블에서의 담당자 N), 담당자가 없을 시 담당자 배정 버튼 생성.
    - `합성 요청 일자`: 합성 요청 일자
    - `합성 완료 일자`: 합성 완료 일자

## 3. UI 디자인 패턴 (My Board 연동)

- **Search Header**: 상단 검색 및 상세 필터(상태, 우선순위, 기간) 레이아웃 유지.
- **Unified Design**: 브랜드 컬러(#F87C63), 둥근 모서리(12px), 은은한 카드 그림자 적용.
- **Interactive Elements**:
    - 담당자 배정 모달 (디자인 고도화).
    - 상태 변경 팝오버 (테이블 내에서 즉시 상태 변경 가능).
    - 행 하이라이트 (선택된 그룹에 대한 브랜드 컬러 하이라이트).
