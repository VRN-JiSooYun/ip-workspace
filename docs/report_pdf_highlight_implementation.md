# 특허 분석 상세 페이지 PDF 연동 및 하이라이트 구현 보고서

## 1. 작업 개요
특허 분석 상세 페이지(`PatentAnalysisDetail.tsx`)에서 화합물 데이터와 PDF 뷰어 간의 상호작용을 고도화하고, 화합물의 위치 정보(BBox)를 PDF 위에 정확하게 하이라이트하는 기능을 구현하였습니다.

## 2. 주요 구현 내용

### 2.1 UI/UX 최적화
- **레이아웃 조정**: 기존 HTML 포털과 유사하게 `Functional Group Analysis` 영역을 세로 배치로 변경하고, 상단에 대표 Scaffold 이미지를 배치하였습니다.
- **내부 스크롤 구현**: 탭 내부 콘텐츠가 길어질 경우 헤더가 고정된 상태에서 내용만 스크롤되도록 `.ant-tabs-tabpane`에 오버플로우 설정을 적용하였습니다.
- **화합물 카드 개선**: 하나의 화합물이 여러 페이지에 등장할 경우를 대비하여 카드 내부에 페이지 이동 버튼(`<`, `>`)을 추가하고 상태 관리를 구현하였습니다.

### 2.2 PDF 하이라이트 연동 기술
- **좌표계 변환 (Coordinate Transformation)**:
    - 문제: API에서 제공하는 `bbox` 좌표는 특정 해상도 기준의 픽셀 좌표인 반면, 라이브러리는 포인트(pt) 기반의 비율 좌표를 사용합니다.
    - 해결: 기존 포털 소스 분석을 통해 `0.36`이라는 변환 계수를 찾아내어 `bboxToPosition` 유틸리티 함수를 구현하였습니다.
    - 동적 크기 감지: `pdfjs`를 사용하여 런타임에 PDF 페이지의 실제 포인트 크기를 가져와 변환 정밀도를 높였습니다.
- **하이라이트 렌더링 엔진 최적화**:
    - `react-pdf-highlighter-plus`의 `AreaHighlight`를 사용하여 텍스트가 아닌 영역 단위의 하이라이트를 지원하도록 `HighlightContainer`를 확장하였습니다.
    - 활성화된 화합물에 대해 빨간색 테두리와 반투명 배경색이 적용되도록 커스텀 CSS를 구현하였습니다.

### 2.3 양방향 상호작용 (Bidirectional Interaction)
- **카드 → PDF**: 화합물 카드 선택 또는 페이지 이동 시 PDF 뷰어가 해당 페이지로 자동 스크롤되고 하이라이트 박스를 표시합니다.
- **스크롤 동기화**: 라이브러리의 `scrollToHighlight` 에러를 방지하기 위해 DOM 기반의 `scrollIntoView` 방식을 보조적으로 활용하여 안정성을 확보하였습니다.

## 3. 기술적 결정 사항
- **DPI/Scale 대응**: PDF 렌더링 스케일과 상관없이 일관된 위치를 유지하기 위해 비율 기반 좌표계(`ScaledPosition`)를 사용하였습니다.
- **상태 관리**: Zustand(`useUIStore`)와 React Local State를 적절히 분리하여 성능 저하 없이 동적인 하이라이트 업데이트가 가능하도록 설계하였습니다.

## 4. 향후 계획
- **정밀도 검증**: 다양한 해상도의 PDF 파일에 대해 BBox 위치가 오차 없이 매핑되는지 추가 검증이 필요합니다.
- **실제 API 연동**: 현재 Mock 데이터 기반으로 동작하는 로직을 실제 백엔드 API 응답 구조에 맞춰 전환할 예정입니다.
