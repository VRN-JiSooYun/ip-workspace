## Compound Search Docker Build 오류 수정

- `compound_search/requirement.txt`에 `fastapi`, `uvicorn`이 서로 다른 버전으로 중복 지정되어 Docker build 중 pip dependency resolver가 실패하는 문제를 수정했습니다.
- 유지한 버전:
  - `fastapi==0.136.3`
  - `uvicorn==0.49.0`
- 제거한 중복 버전:
  - `fastapi==0.116.1`
  - `uvicorn==0.35.0`
