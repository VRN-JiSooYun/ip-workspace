## RDKit draw API 비동기 요청 최적화

- `frontend/src/services/structureRendering.ts`
  - SMILES만 있는 구조는 ChemDraw MOL block 변환을 기다리지 않고 RDKit `/draw`에 바로 SMILES를 전달하도록 변경했습니다.

  - MOL block 변환은 SVG 로딩을 막지 않고 백그라운드로 진행되며, 변환 완료 후 cache에 저장되어 이후 렌더에서 재사용됩니다.
