# Development Status Page

## 작업 범위
- `수리응용2팀 서비스 개발 진행 현황` 메뉴가 실제 프로젝트 현황 페이지를 표시하도록 구현했습니다.
- `sample/math2_ui/math2_ui.png`의 파이프라인 행/확장 상세 UX를 내부 운영툴 톤으로 재해석했습니다.

## 수정 파일
- `frontend/src/pages/DevelopmentStatus.tsx`
- `frontend/src/App.tsx`

## 구현 메모
- 상단에는 전체 서비스 수, 개발중/검토중/완료/보류 개수, 평균 진행률 요약 지표를 배치했습니다.
- 본문은 서비스별 진행률을 `요구사항 → 설계 → UI/UX → 개발 → 테스트 → 배포 → 운영` 단계로 표시하는 파이프라인 리스트로 구성했습니다.
- 각 행 클릭 시 프로젝트 요약, 최근 업데이트, 다음 액션, 블로커, 작업 로그 버튼이 펼쳐집니다.
- 선택된 파이프라인 행과 상세 패널이 하나의 객체처럼 보이도록 외곽 카드 wrapper로 통합하고, 활성 빨간 outline과 상세 영역 잘림처럼 보이는 음수 margin을 제거했습니다.
- 현재는 mock 데이터 기반이며 실제 데이터 연결 시 `projects` 배열을 API 응답으로 대체하면 됩니다.
