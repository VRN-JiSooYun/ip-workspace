# Wieldy - React Admin Template 도입 검토 보고서

`MyWorkspace` 프로젝트의 프론트엔드 UI를 고도화하기 위해 **Wieldy - React Admin Template**을 적용하는 방안에 대한 검토 내용입니다.

## 1. 개요 (Overview)
- **템플릿 명**: Wieldy - React Admin Template
- **핵심 기술**: React, Ant Design (AntD), Redux (Saga), TypeScript, Vite/Next.js
- **용도**: 기업용 대시보드, 복잡한 내부 툴, 데이터 중심 관리 시스템

## 2. 적합성 분석 (Analysis)

### ✅ 장점 (Pros)
1. **Ant Design 기반 완벽 통합**: 우리가 이미 사용 중인 Ant Design 5를 기반으로 하고 있어, 컴포넌트 호환성이 매우 높습니다.
2. **풍부한 사전 구현 페이지**: 캘린더, 파일 관리자, 채팅 등 연구원이 화합물을 관리하며 필요할 수 있는 부가 기능들이 이미 구현되어 있습니다.
3. **고급 레이아웃 옵션**: 10가지 이상의 커스텀 레이아웃을 제공하여, `My Board`나 `SAR Table` 같이 넓은 화면이 필요한 페이지에 맞춤형 사이드바/헤더 구성을 즉시 적용할 수 있습니다.
4. **검증된 디자인 아키텍처**: "Premium Design" 요구사항에 부합하는 현대적이고 세련된 UI/UX를 제공합니다.

### ⚠️ 고려 사항 (Cons/Risks)
1. **학습 곡선**: Redux-Saga 기반의 상태 관리를 권장하므로, 단순한 Zustand 기반의 현재 구조보다 복잡도가 높아질 수 있습니다.
2. **의존성 무거움**: 매우 많은 기능을 포함하고 있어 번들 사이즈가 커질 수 있으며, 불필요한 코드를 제거하는 데 시간이 소요됩니다.
3. **라이선스**: 상용 템플릿이므로 정식 라이선스 구매가 필요할 수 있습니다.

## 3. 적용 시나리오 (Implementation Scenario)

1. **테마 시스템 활용**: Wieldy의 컬러 스킨 및 타이포그래피 설정을 가져와 `MyWorkspace`에 적용하여 심미적 완성도를 극대화합니다.
2. **대시보드 위젯 재사용**: Wieldy에서 제공하는 통계 위젯을 활용하여 주간 화합물 업데이트 현황을 시각화합니다.
3. **레이아웃 전환**: `SAR Table` 페이지 등 특수 화면에서 Wieldy의 'Full Width' 레이아웃을 사용하여 데이터 가독성을 높입니다.

## 4. 최종 결론 (Conclusion)

> [!IMPORTANT]
> **검토 결과: 적극 추천**
>
> `MyWorkspace`는 대량의 데이터(화합물 리스트, SAR 데이터)를 다루고 전문적인 느낌을 주어야 하는 프로젝트입니다. Wieldy는 Ant Design을 가장 세련되게 활용하는 템플릿 중 하나이므로, 이를 기반으로 UI를 재구성하면 개발 속도를 2배 이상 높이면서도 최상급의 퀄리티를 확보할 수 있습니다.
