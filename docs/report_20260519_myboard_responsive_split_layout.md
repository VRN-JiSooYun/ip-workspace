# My Board 반응형 Split Layout 개선

## 요청 요약

My Board처럼 좌측/우측으로 나뉜 두 테이블 화면에서 전체 화면 폭이 모바일 수준으로 줄어들면, 좌우 배열 대신 위/아래 배열로 전환할 수 있는지 확인하고 UX를 개선한다.

## 구현 내용

파일: `frontend/src/pages/MyBoard.tsx`

- viewport 폭이 `1100px` 이하이면 그룹 리스트와 그룹 상세 목록을 세로 stack 레이아웃으로 전환한다.
- 세로 stack 상태에서는 좌우 너비 조절 핸들을 숨긴다.
- 그룹 리스트 패널은 위, 그룹 상세 목록 패널은 아래에 배치한다.
- 좁은 화면에서 페이지 내부를 세로 스크롤할 수 있도록 My Board 루트 컨테이너에 반응형 overflow 처리를 추가했다.
- 그룹 리스트 테이블에도 가로 스크롤을 허용해 컬럼이 좁은 화면에서 깨지지 않도록 했다.
- 검색 영역은 고정폭 `Space` 배치 대신 wrap 가능한 flex 배치로 바꿔 좁은 화면에서 검색 input과 버튼이 줄바꿈되도록 했다.
- `1100px` 이하에서는 상위 그룹 생성 버튼이 한 줄 전체 폭을 사용해 버튼 텍스트가 잘리지 않도록 했다.

## UX 동작

- 데스크톱/태블릿 넓은 화면: 기존처럼 좌측 그룹 리스트, 우측 그룹 상세 목록을 나란히 보여준다.
- 작은 화면: 그룹 리스트를 먼저 보여주고, 선택 결과를 아래의 그룹 상세 목록에서 확인한다.
- 작은 화면에서는 split 조절 핸들이 사라지므로 드래그 조작 없이 자연스럽게 세로 스크롤로 탐색한다.

## 확장 방향

같은 패턴의 좌우 분할 페이지가 추가되면 다음 기준을 공통화할 수 있다.

- breakpoint: `1100px`
- wide layout: `flex-direction: row`
- narrow layout: `flex-direction: column`
- split handle: wide layout에서만 표시
- 각 테이블: `scroll.x = 'max-content'`
