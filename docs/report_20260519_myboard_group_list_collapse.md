# My Board 그룹 리스트 접기/펼치기

## 요청 요약

My Board 페이지에서 그룹 상세 목록을 더 넓게 보고 싶다는 의견에 따라, 좌측 그룹 리스트를 접었다 펼칠 수 있는 UX를 추가한다.

## 구현 내용

파일: `frontend/src/pages/MyBoard.tsx`

- `isGroupListCollapsed` 상태를 추가했다.
- 그룹 리스트 헤더 좌측에 접기 버튼을 추가했다.
- 그룹 리스트가 접힌 상태에서는 그룹 리스트 패널과 split 조절 핸들을 숨긴다.
- 그룹 상세 목록은 접힌 상태에서 전체 폭을 사용한다.
- 그룹 상세 목록 헤더 좌측에 펼치기 버튼을 표시해 다시 그룹 리스트를 열 수 있게 했다.
- 기존 선택 그룹, 필터, 상세 목록 데이터 상태는 유지된다.

## UX 동작

- 기본 상태: 기존처럼 그룹 리스트와 그룹 상세 목록이 함께 표시된다.
- 접기 클릭: 그룹 리스트가 숨겨지고 그룹 상세 목록이 전체 폭으로 확장된다.
- 펼치기 클릭: 그룹 리스트가 다시 나타나고 기존 split 레이아웃으로 돌아간다.
- `1100px` 이하 stack 레이아웃에서도 접기/펼치기 동작은 유지된다.
