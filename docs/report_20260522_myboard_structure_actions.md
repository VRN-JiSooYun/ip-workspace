# MyBoard Structure Column Action UX Update

## 요청
- My Board 페이지의 화합물 구조 컬럼 UX를 첨부 이미지(`sample/ui/img.png`) 기준으로 개선.
- SVG 이미지와 버튼이 겹치지 않도록 분리.
- 버튼 위치를 구조 이미지 우측 액션 영역으로 이동.

## 구현 내용
- `frontend/src/pages/MyBoard.tsx`의 그룹 리스트 대표 구조 컬럼과 그룹 상세 목록 `화합물 구조` 컬럼 렌더링을 수정.
- 구조 SVG 프레임과 확대 버튼을 같은 프레임 안에 겹쳐 배치하지 않고, `inline-flex` 레이아웃으로 분리.
- 확대 버튼과 SVG 복사 버튼은 구조 프레임 우측의 세로 액션 영역에 배치.
- 액션 영역 높이를 구조 프레임과 동일하게 지정해 버튼이 상단부터 아래 방향으로 정렬되도록 조정.
- 액션 영역은 작은 캡슐형 레일로 스타일링해 단일 버튼이 떠 보이는 어색함을 줄임.
- 구조 데이터 복사 버튼은 `smiles`, `molBlock/mol_block/molblock`, `svg` 순서로 사용 가능한 값을 복사하도록 변경.
- 버튼 레일이 옆 컬럼을 침범하지 않도록 그룹 리스트 대표 구조 컬럼과 상세 목록 구조 컬럼 폭을 레일 포함 기준으로 확대.
- table row hover/selected 하이라이트 시 버튼 레일 배경이 따로 떠 보이지 않도록 액션 영역 배경/테두리를 투명 처리.
- 기존 구조 프레임 크기는 유지해 컬럼 폭 변화와 테이블 레이아웃 영향을 최소화.

## 검증
- 프로젝트 지침상 빌드/실행은 수행하지 않음.
