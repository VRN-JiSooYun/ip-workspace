# 의견제출통지서 관련도 자동 정렬 계획

## 목적

키워드 검색 시 외부 검색 API가 적용하는 관련도 정렬을 UI에 명확히 표시하고 관련도 점수를
중계 응답에서 보존한다.

## 작업 범위

1. 외부 검색 API의 정렬 계약과 `relevance_score` 응답을 확인한다.
2. backend wire 타입과 frontend 응답 타입에 관련도 점수를 추가한다.
3. 키워드 검색 시 Sort By를 `관련도순`, 키워드가 없으면 발행일자순으로 자동 전환한다.
4. backend 매핑 테스트와 장기 API 문서를 갱신한다.

## 정렬 기준

외부 API에 별도 sort parameter가 없으므로 서버가 반환한 전역 정렬을 유지한다. 프런트에서
현재 페이지만 다시 정렬하지 않는다.
