# Synthesis Board 반응형 Stack Layout 개선

## 요청 요약

합성보드 페이지도 전체 화면 폭이 모바일 수준으로 줄어들면 좌우 배열 대신 위/아래 배열로 전환되도록 UX를 개선한다.

## 구현 내용

파일: `frontend/src/pages/SynthesisBoard.tsx`

- `1100px` 이하에서 합성 그룹 리스트와 합성 상세 목록을 세로 배치로 전환했다.
- 넓은 화면에서는 기존 `14:10` 좌우 컬럼 배치를 유지한다.
- 좁은 화면에서는 두 영역 모두 `span=24`로 전환되어 위/아래로 표시된다.
- 좁은 화면에서는 페이지 내부 세로 스크롤을 허용한다.
- 모바일 stack 상태에서는 테이블 내부 고정 높이 스크롤을 풀고, 페이지 스크롤 중심으로 탐색하도록 조정했다.
- 합성 상세 테이블에는 가로 스크롤을 추가해 좁은 화면에서 컬럼이 잘리지 않도록 했다.

## UX 동작

- 데스크톱/넓은 화면: 합성 그룹 리스트와 합성 상세 목록이 좌우로 표시된다.
- `1100px` 이하: 합성 그룹 리스트가 위, 합성 상세 목록이 아래로 표시된다.
- 상세 목록의 Table/Canvas/Tree 전환 UI는 기존 위치와 기능을 유지한다.
