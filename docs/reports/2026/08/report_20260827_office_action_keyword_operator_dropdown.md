# Office Action 키워드 조건 연산자 Dropdown

## 작업 목적

검색바의 키워드 연산자를 상시 노출하지 않고 두 번째 조건부터 추가 시점에 선택하게 한다.

## 변경 내용

- 검색바의 상시 operator Select를 제거했다.
- 첫 키워드는 `조건 추가`로 즉시 포함 조건에 추가한다.
- 조건이 하나 이상이면 `조건 추가` 버튼이 Dropdown 트리거로 바뀌며 `AND`, `NOT`을 제공한다.
- 외부 Search API에서 정상 동작하지 않는 OR은 기존과 동일하게 노출하지 않는다.
- 조건 태그 사이에 선택한 연산자를 표시하고 태그 본문에서는 중복 연산자 문구를 제거했다.
- 기존 조건과 미확정 draft가 함께 있으면 연산자를 선택하기 전까지 검색 버튼을 비활성화한다.
- 검색어 Enter는 Search API를 호출하지 않고 기존 호환 동작대로 AND 조건을 추가한다.

## 검증 결과

- Search API를 실행하는 검색 버튼과 연산자를 선택하는 조건 추가 Dropdown의 이벤트 경계를 확인했다.
- 첫 조건은 항상 포함 조건이어서 외부 API가 첫 연산자를 무시하는 제약에 걸리지 않는다.
- 조건 삭제로 NOT만 남은 경우 기존 제외 조건 경고와 검색 차단이 유지된다.
- 변경 diff의 공백 오류를 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드, 테스트 및 개발 서버 실행은 수행하지 않았다.
