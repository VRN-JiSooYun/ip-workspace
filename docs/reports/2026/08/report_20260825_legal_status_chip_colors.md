# 법적상태 Chip 색상 규칙 작업 보고서

## 작업 목적

법적상태를 빠르게 구분할 수 있도록 상태 의미별 Chip 색상을 통일한다.

## 변경 내용

- 공통 `getLegalStatusTagColor` 함수를 추가했다.
- 공개는 파란색, 거절은 빨간색, 등록은 주황색으로 표시한다.
- 취하 또는 포기가 포함된 상태는 회색으로 표시한다.
- 그 밖의 상태(Pending 포함)는 노란색 계열로 표시한다.
- 설명이 붙은 상태도 분류되도록 완전 일치가 아니라 핵심어 포함 여부를 사용한다.
- 의견제출통지서 결과 카드, 문서 뷰어, 특허 관리 목록에 같은 규칙을 적용했다.
- OA DB에서 확인한 법적상태 7~10번도 검색 결과에서 이름이 보이도록 fallback 매핑을 보완했다.
- 결과 카드에서 기존 브랜드색을 강제하던 CSS를 제거해 Ant Design Tag 색상이 적용되게 했다.

## 검증 결과

- 세 법적상태 표시 위치가 공통 함수를 사용하는지 정적으로 확인했다.
- `git diff --check`로 공백 오류가 없는지 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드·실행은 수행하지 않았다.
