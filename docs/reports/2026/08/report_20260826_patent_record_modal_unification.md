# 관리 특허 추가·수정 모달 통합 작업 보고서

## 작업 목적

`patent-management`의 관리 특허 추가 화면을 별도 폼 모달로 유지하지 않고, 관리 특허 수정 화면과 동일한 컴포넌트 및 2단 레이아웃을 사용하도록 통합한다.

## 변경 내용

- `PatentRecordDetailModal`에 `create`와 `edit` 모드를 추가했다.
- 생성 모드에서는 수정 화면과 동일한 제목·설명·사이드 필드 배치를 사용한다.
- 생성 중 입력값은 서버에 즉시 전송하지 않고 로컬 초안에 보관하며, 하단 `추가` 버튼을 누르면 기존 생성 API로 한 번에 전송한다.
- 생성 필수값인 국가와 출원번호를 제출 시 검증하고 누락 필드에 오류 상태를 표시한다.
- 생성 전에는 사용할 수 없는 활동 피드, 문서 연결, To-do, 생성·수정 시각 영역을 생성 모드에서 숨겼다.
- 타이틀 바는 평상시 기존 Tag·텍스트 디자인을 유지하고, 항목을 클릭했을 때만 편집 컨트롤로 전환한다.
- Target은 편집 중 lookup 기반 Select로, 내부관리번호와 출원번호는 인라인 Input으로 전환한다. 수정 모드에서는 blur 또는 Enter로 저장하며, 생성 모드에서는 로컬 초안에 반영한다.
- 생성 모드에서 내부관리번호가 비어 있으면 실제 값처럼 보이는 문구를 채우지 않고 `내부관리번호` placeholder 스타일 안내를 표시한다.
- `PatentManagement`에서는 추가와 수정에 `PatentRecordDetailModal` 인스턴스 하나만 사용하도록 변경했다.
- 더 이상 사용하지 않는 `PatentRecordFormModal.tsx`를 삭제했다.

## 검증 결과

- `PatentRecordFormModal` import 및 사용처가 남아 있지 않음을 검색으로 확인했다.
- 추가·수정 모드 전환 시 서로의 열림 상태가 남지 않도록 상태 초기화를 확인했다.
- `git diff --check`로 변경 파일의 공백 오류가 없음을 확인했다.

## 미실행 항목

- 프로젝트 지침에 따라 빌드와 실행은 수행하지 않았다. 실제 브라우저에서 추가 모달 열기, 필수값 검증, 등록 성공 후 목록 갱신을 확인해야 한다.
