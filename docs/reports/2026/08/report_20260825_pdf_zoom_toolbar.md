# PDF 툴바 확대·축소 기능 작업 보고서

## 작업 목적

`PatentPdfToolbar`에서 PDF 문서의 실제 렌더링 배율을 확대·축소하고 현재 배율을 확인할 수 있도록 한다.

## 변경 내용

- PDF 툴바에 축소, 현재 배율, 확대 버튼을 추가했다.
- 25%, 50%, 75%, 100%, 125%, 150%, 200%, 250%, 300%, 400% 단계로 배율을 조절한다.
- 현재 배율 버튼을 누르면 기존 기본값인 페이지 너비 맞춤(`page-width`)으로 복원한다.
- pdf.js의 `scalechanging` 이벤트를 구독해 페이지 너비 맞춤과 사용자 배율 변경 결과를 툴바에 동기화한다.
- `PdfHighlighter`의 `pdfScaleValue`를 현재 확대·축소 모드와 동기화해 재렌더링이나 컨테이너 크기 변경 시 `page-width`로 되돌아가지 않도록 했다.
- 공용 툴바를 사용하는 특허 분석 화면과 특허 문서 전문 화면에 동일하게 연결했다.

## 검증 결과

- 정적 코드 검토로 툴바 props와 두 사용처의 연결을 확인했다.
- 확대·축소 한계에서 해당 버튼이 비활성화되도록 확인했다.
- 라이브러리의 ResizeObserver가 다시 적용하는 배율 prop이 사용자 선택값을 유지하는지 정적으로 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드와 실행은 수행하지 않았다.
- 브라우저에서 실제 PDF 렌더링 및 하이라이트 정렬 동작은 사용자의 실행 환경에서 확인이 필요하다.
