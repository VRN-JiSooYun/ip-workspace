# 우측 레일 '넓게 보기'

## 작업 목적

"`.rs-root > .rs-shell`의 폭 제한을 풀어 달라"는 요구를 **본문 최소 폭 보호를 깨지 않고**
만족시킨다. 폭을 더 넓히는 대신, 패널이 본문을 **덮는** 모드를 추가했다.

## 왜 상한을 그대로 두었나

`.rs-shell`에는 CSS 상한이 없고, 실제로 막는 것은 세 가지다.

| 제한 | 값 | 위치 |
| --- | --- | --- |
| 절대 상한 | 1000px 고정 | `RAIL_MAX_WIDTH` |
| 본문 보호 | `창폭 − 56 − 14 − 480` | `RightSidebar.MIN_MAIN_WIDTH` |
| 좁은 화면 | ≤900px에서 패널 숨김 | `rightSidebar.css` |

본문 보호는 [report_20260824_right_sidebar.md](./report_20260824_right_sidebar.md)에서 극단
드래그로 **본문이 129px까지 짓눌리던 것**을 막으려고 넣은 방어선이다. 풀면 그 버그가 그대로
돌아온다. 그래서 폭을 늘리는 대신, 넓게 보고 싶다는 요구의 실체(문서를 화면 가득 보기)를
덮는 모드로 만족시킨다. 이 모드에서는 패널이 흐름 밖으로 나가 본문 위에 얹히므로 본문을
전혀 밀지 않는다.

## 변경 내용

### `frontend/src/components/layout/RightSidebar.tsx`
- `wide` 상태와 패널 머리줄의 토글 버튼(`Maximize2`/`Minimize2`, `aria-pressed`)을 추가했다.
- 켜면 셸 폭이 `창폭 − 56`(아이콘 레일 자리는 남긴다)이 되고 `.rs-shell-wide`가 붙는다.
- 셸이 흐름에서 빠지면 본문이 그만큼 넓어졌다가 모드를 끌 때 되돌아온다. 가려진 채로 본문을
  두 번 다시 배치하는 셈이라, 셸이 쓰던 자리를 `.rs-shell-spacer`로 그대로 잡아 둔다.
- 나가는 길은 토글과 **Esc** 두 가지다. 레일을 접으면 함께 꺼진다(다시 펼 때 화면이 덮인 채로
  열리면 놀란다).
- 저장하지 않는다. 읽는 동안만 쓰는 모드라, 새로고침 후 본문이 가려진 채 시작하는 것보다
  꺼진 채 시작하는 편이 덜 놀랍다. 화면 이동으로는 유지된다(레일이 레이아웃에 있다).

### `frontend/src/components/common/ResizableSidePanel.tsx`
- `onExpandBeyondMax` 추가. 상한보다 `EXPAND_SLACK`(64px) 더 밀면 부른다. 최소 폭 아래로 밀면
  접히는 `onCollapse`와 같은 자리의 반대편이다.
- 상한 계산을 `effectiveMaxWidth()`로 빼서 `clamp()`와 이 판정이 같은 값을 쓰게 했다.
- 키보드도 같다 — 이미 상한인데 ←를 한 번 더 누르면 `onExpandBeyondMax`가 불린다.
- 폭은 상한에 둔 채로 넘긴다. 거기까지 민 것은 사용자가 원한 폭이 맞고, 모드를 껐을 때
  돌아갈 자리이기도 하다(접을 때 드래그 시작 폭으로 되돌리는 것과 다른 점).

### `frontend/src/components/layout/rightSidebar.css`
- `.rs-shell-wide`: `position: fixed; right: 56px; z-index: 900`. 오른쪽 경계가 흐름일 때와
  같아서 폭 전환이 자리 이동 없이 왼쪽으로 자라는 모양이 된다. z-index는 앱 안에서 쓰는
  값(최대 60)보다 위, antd 팝업(1030~)보다 아래다 — 패널 안에서 연 드롭다운은 그 위에 떠야 한다.
- 넓어진 셸을 패널이 채우도록 `.rs-shell > *`의 `flex: 0 0 auto`를 이 모드에서만 뒤집는다.
  저장된 폭은 건드리지 않는다(모드를 끄면 그 폭으로 돌아간다).
- 이 모드에서는 폭 조절 핸들을 감춘다. 폭이 '가능한 만큼'으로 정해져 조절할 것이 없고,
  남겨 두면 핸들이 화면 왼쪽 끝에 붙는데 거기서 시작한 드래그는 첫 이동부터 이미 상한을
  한참 넘은 위치라 곧바로 이 모드로 되돌아온다 — 잡히지 않는 손잡이가 된다.
- `.rs-shell-spacer`, 토글 버튼 스타일, ≤900px에서 spacer도 함께 숨김.

## 미실행 항목

- `RAIL_MAX_WIDTH = 1000` 고정값은 그대로 두었다. 넓은 모니터에서 이 값이 먼저 걸리는 것은
  사실이지만, 이번 요구는 '넓게 보기'로 충족된다. 화면 비율 상한으로 바꾸는 것은 별건이다.
- `computeMaxWidth()`가 좌측 Sider(220px/64px)를 빼지 않아 "본문 480 보장"이 실제로는 콘텐츠
  260px 보장인 문제는 그대로다. 고치면 상한이 줄어 이번 요구와 방향이 반대라 함께 판단이 필요하다.
- 검증 중 개발 서버의 `right-sidebar:v1` 저장값(문서 패널 폭)이 드래그로 바뀌었다. 화면에서
  다시 끌면 되는 값이라 되돌리지 않았다.
