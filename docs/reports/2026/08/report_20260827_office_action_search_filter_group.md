# Office Actions 검색·필터 그룹화 작업 보고서

## 작업 목적

`office-actions` 화면의 기본 검색 바와 상세 필터가 간격을 둔 별도 카드로 보여, 하나의
검색 요청을 구성하는 연속된 작업이라는 관계가 약하게 느껴지는 문제를 개선한다.

## 변경 내용

- `oa-searchbar`와 `oa-filters`를 `oa-search-controls` 영역으로 묶었다.
- 두 영역이 하나의 12px 카드 외곽선과 모서리를 공유하도록 변경했다.
- 검색 바와 상세 필터 사이의 빈 간격을 없애고 1px 내부 구분선만 두었다.
- 검색 조건 묶음에 `section`과 접근성 레이블을 적용해 문서 구조에서도 하나의 영역으로
  인식되도록 했다.
- 검색 및 필터의 상태 관리, API 요청, 펼침/접힘 동작은 변경하지 않았다.

## 검증 결과

- 변경 diff를 확인해 기존 검색·필터 로직에는 변화가 없고 레이아웃 래퍼와 전용 스타일만
  추가된 것을 확인했다.
- 기존의 컨테이너 쿼리 기준(`oa-searchbar`, `oa-filters`)은 각 컴포넌트에 그대로 유지된다.

## 미실행 항목

- 저장소 지침에 따라 빌드 및 실행 기반 화면 확인은 수행하지 않았다.
