# 관리 특허 상세 모달 JIRA형 레이아웃 개선 보고서

## 작업 목적

첨부된 JIRA 이슈 상세 화면의 정보 계층과 조작 방식을 참고해 `PatentRecordDetailModal`을 넓은 작업 화면 형태로 개선한다. 기존 특허 생성·필드별 수정·문서 연결·To-do·감사 이력 기능은 유지한다.

## 변경 내용

- 모달을 화면 폭과 높이를 적극적으로 사용하는 대형 작업 화면으로 확장하고, 헤더·본문·생성 footer를 분리했다.
- 모달 전체 높이를 viewport의 80%(`80vh`)로 고정하고 `top: 10vh`로 배치해 위·아래 여백을 각각 10% 유지한다.
- 상단 특허 식별 영역을 `Target / 내부관리번호 / 출원번호` breadcrumb 형태로 정리했다. 평상시에는 기존 Tag·텍스트 표현을 유지하고 클릭할 때만 편집 컨트롤로 전환한다.
- 왼쪽 본문은 큰 특허 명칭, 문서·문서 연결·To-do 액션, 설명, 활동 이력 순서로 재배치했다.
- 문서와 To-do 동작을 제목 아래의 작고 명확한 액션 버튼으로 모으고, 우측 연결 그룹의 중복 버튼을 제거했다.
- 오른쪽에는 법적 상태 선택을 독립 배치하고, 세부 사항·연결·심사 상태·일자·번호·국제 정보 등을 각각 카드형 Collapse로 구성했다.
- 왼쪽 본문과 우측 패널 사이에 hover·focus·드래그 중에만 보이는 divider를 추가했다. divider를 좌우로 드래그하거나 키보드 방향키로 우측 패널 폭을 300~560px 범위에서 조절할 수 있다.
- divider의 원형 화살표 버튼으로 우측 패널을 접고 펼칠 수 있으며, 작은 화면에서는 divider를 숨기고 단일 열 레이아웃을 우선한다.
- 우측 필드의 라벨과 값을 세로로 배치하고, 평상시 입력 테두리를 낮춘 뒤 hover/focus 시 편집 가능성이 드러나도록 조정했다.
- 활동 이력을 카드형 타임라인에 가깝게 표현하고, 제목·설명·버튼·스크롤·모달 닫기 버튼의 크기와 간격을 JIRA 화면에 맞춰 조정했다.
- 980px 및 760px 이하 화면에서 패널 폭을 축소하거나 단일 열로 전환하는 반응형 규칙을 추가했다.

## 검증 결과

- 기존 저장 핸들러, 문서 열기·연결, To-do 열기, 감사 이력 컴포넌트가 새 위치에서도 동일한 콜백을 사용함을 확인했다.
- 생성 모드에서는 문서·To-do 액션을 노출하지 않고 필수 입력이 있는 기본·번호 그룹을 기본으로 펼치도록 확인했다.
- divider의 pointer capture, 최소·최대 폭 제한, 접힘 상태의 접근성 속성과 모바일 fallback을 정적으로 확인했다.
- `git diff --check`로 공백 오류가 없음을 확인했다.

## 미실행 항목

- 프로젝트 지침에 따라 빌드와 실행은 수행하지 않았다. 실제 브라우저에서 라이트·다크 테마, 긴 필드값, 작은 화면, 생성 footer 및 각 Collapse의 스크롤 동작을 확인해야 한다.
