# Office Action 법조문·IPC 조건별 결합 연산자

## 작업 목적

법조문과 IPC의 결합 연산자를 상시 노출하지 않고, 두 번째 조건부터 추가 시점에 AND/OR를 선택하게 한다.

## 변경 내용

- 법조문과 IPC subpanel의 상시 `조건 결합` Select를 제거했다.
- 각 그룹의 첫 조건은 `추가` 버튼으로 즉시 추가한다.
- 같은 그룹에 조건이 하나 이상 있으면 `추가` 버튼 클릭 시 버튼 아래 Dropdown에 `AND`, `OR`를 표시한다.
- Dropdown에서 선택한 연산자를 새 조건에 저장하고 태그 사이에 표시한다.
- 서로 다른 연산자를 연속해서 선택할 수 있으며, 혼합식은 일반적인 규칙대로 AND를 먼저 계산한 뒤 OR로 결합한다.
- AND는 서로 다른 관계 행이 각각의 조건을 만족할 수 있도록 처리한다.
- Enter 자동 적용으로 후속 draft 조건을 추가할 때는 기존 OR 동작을 기본값으로 사용한다.
- 조건 연산자는 프런트 필터 상태로만 관리하고 Search API payload에서는 제거한다.

## 검증 결과

- Search API 변환 시 법조문과 IPC 조건의 `operator`가 payload에 포함되지 않도록 명시적으로 매핑했다.
- 조건이 없는 경우, 단일 조건, OR 조건, AND 조건 및 혼합 조건의 평가 경로를 정적으로 확인했다.
- 조건 삭제 후 첫 번째가 된 항목의 저장된 연산자는 평가와 화면에서 무시된다.
- 변경 diff의 공백 오류를 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드, 테스트 및 개발 서버 실행은 수행하지 않았다.
