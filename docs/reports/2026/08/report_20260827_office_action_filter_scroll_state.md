# Office Action 필터 상태 기반 스크롤 전환

## 작업 목적

낮은 화면에서 `oa-page`가 항상 페이지 스크롤 모드로 전환되던 동작을 상세 필터의 펼침/접힘 상태와 연결한다.

## 변경 내용

- 화면 높이가 820px 이하이면서 `oa-filters`가 펼쳐진 경우에만 `oa-page`를 세로 스크롤 영역으로 전환했다.
- 필터가 접힌 경우에는 기본 레이아웃을 유지해 `oa-result-cards`가 결과 목록의 스크롤을 담당하도록 했다.
- Ant Design Collapse가 제공하는 `.ant-collapse-item-active` 상태를 CSS `:has()`로 감지해 React 상태나 별도 클래스를 추가하지 않았다.
- 페이지 스크롤에는 `overflow-y: auto`를 사용하므로 실제 콘텐츠가 화면 높이를 넘을 때만 스크롤바가 표시된다.

## 검증 결과

- 필터가 펼쳐진 낮은 화면에서만 페이지 스크롤 전환 규칙이 적용되는 선택자 구조를 확인했다.
- 필터가 접히거나 화면 높이가 820px을 초과하면 기존 결과 목록 스크롤 구조가 유지된다.
- `git diff --check`로 공백 및 패치 형식 오류가 없는지 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드 및 개발 서버 실행은 수행하지 않았다.
