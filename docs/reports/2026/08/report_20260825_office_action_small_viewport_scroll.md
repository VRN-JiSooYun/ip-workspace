# Office Actions 작은 화면 스크롤 개선 작업 보고서

## 작업 배경

`MainLayout`의 본문 스크롤을 제거한 상태에서 Office Actions 화면은 검색 바와 필터를
고정하고 결과 카드 목록만 내부 스크롤하도록 구성되어 있었다. 뷰포트 높이가 낮으면 펼쳐진
필터가 가용 높이를 대부분 차지하여 결과 목록을 탐색하기 어려웠다.

## 변경 내용

- 뷰포트 높이가 `820px` 이하일 때 `.oa-page`를 화면 전용 세로 스크롤 영역으로 전환했다.
- 해당 환경에서는 결과 카드 목록의 내부 스크롤을 해제하고, 필터와 결과가 하나의 문서
  흐름으로 이어지도록 변경했다.
- 일반 높이 화면에서는 기존의 검색/필터 고정 및 결과 카드 내부 스크롤 방식을 유지했다.
- `MainLayout`의 전역 `overflow: hidden` 정책은 변경하지 않아 다른 화면에는 영향을 주지 않는다.

## 확인 사항

- 저장소 지침에 따라 빌드와 실행은 수행하지 않았다.
- CSS 변경 범위는 Office Actions 페이지로 한정했다.
