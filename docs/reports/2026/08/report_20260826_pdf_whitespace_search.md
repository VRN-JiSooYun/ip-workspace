# PDF 줄바꿈 무시 검색 작업 보고서

## 작업 목적

PDF 텍스트 레이어에서 한 단어가 여러 span 또는 줄로 나뉜 경우에도 공백 없는 검색어로
찾을 수 있게 한다. 예를 들어 `제출기`와 `일` 사이에 PDF 줄바꿈이 있어도 `제출기일`로
검색되어야 한다.

## 변경 내용

- PDF.js `PDFFindController.match()`에 공백 무시 검색 어댑터를 설치했다.
- 검색어와 페이지 검색용 텍스트에서 Unicode 공백을 제거한 뒤 기존 PDF.js matcher를
  사용하도록 했다.
- 압축 문자열의 각 UTF-16 offset과 원문 offset의 대응표를 만들어, 검색 결과를 원래
  텍스트 범위로 복원한다.
- 복원된 범위에는 줄바꿈 공백이 포함되므로 기존 PDF.js 하이라이트와 이전/다음 결과 이동을
  그대로 사용한다.
- 다중 query 등 현재 화면이 사용하지 않는 PDF.js 검색 계약은 기존 matcher로 통과시킨다.
- `Symbol.for` 표식을 사용해 같은 find controller에 어댑터가 중복 설치되지 않게 했다.

## 검증 결과

- `제출기 일` 페이지 텍스트를 `제출기일`로 검색할 때 compact match가 원문의 공백을 포함한
  범위로 복원되는 흐름을 정적으로 확인했다.
- 기존 검색 이벤트, 결과 건수, 하이라이트 및 이전/다음 이동 API는 변경하지 않았다.
- 변경 파일에 whitespace 오류가 없는지 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드·테스트·Docker 실행은 수행하지 않았다.
