# 2026.06.24 작업 보고서

## MyBoard Tree React Flow 전환

### 변경 내용
- MyBoard `Tree` 탭의 정적 absolute-position/SVG connector 기반 tree canvas를 React Flow 기반 canvas로 전환했다.
- `@xyflow/react` 의존성을 `frontend/package.json`에 추가했다.
- 기존 tree node 카드 UI는 React Flow custom node로 재사용했다.
  - 화합물 구조 표시 및 preview modal 연동 유지
  - Binding score, LogP, TPSA, MW metric 표시 유지
  - MolProp RadarChart 표시 유지
- parent-child 관계는 React Flow `smoothstep` edge와 arrow marker로 표현하도록 변경했다.
- React Flow viewport 기능을 사용해 pan, zoom, fit view, minimap을 제공한다.
- 캔버스 좌측 React Flow 기본 controls는 상단 toolbar와 중복되어 숨겼다.
- React Flow 기본 background overlay 대신 MyBoard Tree canvas shell의 radial dot background를 사용한다.
- 상단 toolbar에 MiniMap 표시/숨김 toggle button을 추가했다.
- Tree canvas 스타일은 기존 MyBoard theme 변수와 dark mode에 맞춰 보정했다.
- node drag 이동은 React Flow 내부 store에서만 처리한다.
  - DB/localStorage/Zustand 저장은 아직 하지 않는다.
  - mock tree source가 다시 계산되거나 페이지를 새로 열면 초기 위치로 돌아간다.
  - drag 중 React controlled state 갱신을 피해서 node 이동 프레임 저하를 줄였다.
- 우측 끝 node도 canvas 여백으로 이동할 수 있도록 `nodeExtent`를 pan 가능 영역과 맞춰 확장했다.

### 구현 파일
- `frontend/src/pages/MyBoard.tsx`
  - React Flow import 및 custom node 타입 추가
  - 기존 `renderTreeNode`, SVG connector 계산, 수동 scale wrapper 제거
  - `treeFlowNodes`, `treeFlowEdges` 변환 로직 추가
  - zoom/fit/focus 동작을 React Flow instance API로 변경
  - React Flow `defaultNodes/defaultEdges` 기반 임시 node drag 이동 처리 추가
- `frontend/src/index.css`
  - React Flow stylesheet import 추가
  - `.react-flow__edge-path`, controls, minimap, handle 스타일 보정
  - 기존 tree node card 스타일은 React Flow custom node 안에서 계속 사용
- `frontend/package.json`
  - `@xyflow/react` 의존성 추가

### 확인 사항
- 로컬 workspace에는 아직 `frontend/node_modules/@xyflow/react`가 설치되어 있지 않아 TypeScript build는 실행하지 않았다.
- Docker/Bun 환경에서 의존성 설치 후 build 확인이 필요하다.

### 후속 작업
- 실제 API tree lineage 데이터가 확정되면 현재 mock `treeNodes` position 배열을 서버 데이터 기반 layout으로 교체한다.
- 자동 layout이 필요해지면 React Flow dagre/elk layout 예제를 기준으로 layout engine 연동을 검토한다.
