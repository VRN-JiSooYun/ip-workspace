어제 진행된 My Board 및 SAR Table 페이지의 UI/UX 고도화 및 기능 구현 내용을 정리한 문서입니다.

## 1. My Board 페이지 고도화

### 디자인 등록 (Create Design) 팝업 구현
- **필수 항목 구성**: 기획서 사양에 따라 Name, Source, SMILES, Draw 영역을 필수 입력 항목으로 구현.
- **그룹 자동 바인딩**: 그룹 리스트에서 선택된 그룹이 있을 경우, 팝업 오픈 시 해당 그룹이 'Group' 필드에 자동으로 세팅되도록 구현.
- **SMILES-Draw 연동 레이아웃**: ChemDraw 에디터 연동을 고려한 프리뷰 영역 및 에디터 호출 버튼 배치.
- **Calculations 체크박스**: '3D PSA QM', 'Solubility QM/DL', 'E-Sol QM', 'Permeability MD', '특허성', '합성기능성' 등 7종의 계산 항목 선택 기능 추가.
- **Memo & Attachment**: 기존 '비고'를 'Memo'로 변경하고, 드래그 앤 드롭 방식의 파일 첨부(Upload) 기능 추가.
- **독립적 그룹 선택**: 팝업 내 그룹 선택이 배경의 그룹 리스트 체크 상태와 충돌하지 않도록 전용 로컬 상태로 분리 관리.

### UI/UX 개선 및 버그 수정
- **명칭 변경**: '폴더 리스트'를 '그룹 리스트'로 일원화.
- **테이블 설정**: 컬럼 가시성 및 순서 조정(DND) 기능을 Stitch 디자인 가이드에 맞춰 폴리싱.
- **에러 해결**: `Divider`, `Palette` 아이콘 등 누락된 컴포넌트 임포트 수정 및 상세 필터 내 변수 참조 에러(`allProjectOptions`) 해결.

## 2. SAR Table 페이지 전면 개편

### 다층 헤더 테이블 (Multi-level Table)
- **복합 구조 재현**: Enzyme IC50(WT, D1228N 등), Cell GI50, PK(Plasma, Lung, Brain) 등 복잡한 계층 구조의 헤더를 이미지 프로토타입과 동일하게 구현.
- **디자인 통일**: My Board와 동일한 톤앤매너(밝은 그레이 헤더, 브랜드 오렌지 포인트 컬러) 적용.

### 인터랙티브 카드 리스트
- **상단 비주얼 영역**: 화합물 구조가 포함된 카드 리스트를 가로 스크롤 형태로 배치.
- **하이라이트 연동**: 상단 카드 클릭 시 하단 테이블의 해당 행이 코랄색(#fff7f6)으로 강조되며 동기화되도록 구현.

### Heatmap (Coloration) 기능
- **상대 수치 강조**: 좌측 상단 'C' 버튼 클릭 시, 데이터 셀의 수치에 따라 상대적인 농도의 배경색이 적용되어 데이터 경향성을 한눈에 파악 가능.
