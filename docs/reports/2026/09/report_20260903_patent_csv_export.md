# Patent management CSV 다운로드

## 작업 목적

특허 관리 화면의 현재 검색·상세 필터 결과 전체를 CSV로 내려받을 수 있게 한다. 화면에
표시된 한 페이지만 저장되는 누락을 막고, 내려받은 파일을 기존 CSV 업로드 흐름에서도 다시
사용할 수 있게 한다.

## 변경 내용

- `GET /api/patent-records/export` 엔드포인트를 추가했다.
- 목록과 동일한 검색어, Target, 진행 단계, 상세 검색 조건과 정렬을 적용하되 페이지 구분
  없이 조건에 맞는 전체 행을 조회한다.
- CSV 컬럼명과 순서는 기존 업로드 템플릿의 `PATENT_CSV_COLUMNS`를 정본으로 공유한다.
- 쉼표·따옴표·개행은 RFC 4180 방식으로 이스케이프하고 Excel용 UTF-8 BOM을 유지한다.
- 날짜는 `YYYY-MM-DD`, 심사청구는 `청구`/`미청구`로 내보낸다.
- 설명의 WYSIWYG HTML은 재업로드 시 태그가 본문으로 변하지 않도록 평문으로 변환한다.
- 목록 헤더에 읽기 권한 사용자 모두 사용할 수 있는 `CSV로 다운로드` 버튼을 추가했다.
- 브라우저 이동 링크가 아니라 인증 쿠키를 포함한 파일 요청으로 내려받고, 실패하면 현재
  화면을 유지한 채 오류 메시지를 표시한다.

## 검증 결과

- CSV 생성 단위 테스트를 추가해 헤더 순서, 날짜, 관계명, 쉼표와 설명 HTML 제거를
  검증하도록 했다.
- 정적 검토로 화면 목록과 다운로드가 동일한 필터 객체를 사용하는지 확인했다.

## 미실행 항목

- 저장소 지침에 따라 테스트, 빌드와 브라우저 실행은 수행하지 않았다.
