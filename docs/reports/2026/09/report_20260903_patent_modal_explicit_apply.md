# 특허 추가·수정 모달 명시적 적용 UX

## 작업 목적

특허 수정 모달의 select·날짜·체크박스·텍스트 변경이 클릭 즉시 저장되던 동작을
로컬 초안 방식으로 바꾸어 오클릭으로 인한 의도하지 않은 변경을 막는다.

## 변경 내용

- 수정 모달을 열 때 서버 값을 복사한 로컬 초안을 만들고 모든 편집을 초안에만
  반영한다.
- 우측 하단에 `취소`·`적용` 버튼을 배치했다.
- 원본과 달라진 필드가 없으면 `적용` 버튼을 비활성화한다.
- `적용`은 달라진 필드만 하나의 PATCH와 requestId로 저장해 변경 이력을 한 조작으로
  묶는다.
- 하단 `취소`는 초안을 버리고 닫으며, X·배경·Esc로 닫을 때 미적용 변경이 있으면
  폐기 확인을 보여 준다.
- 적용 중에는 입력·버튼을 비활성화하고, 실패하면 초안을 유지한 채 하단에
  오류를 표시한다.
- 설명 편집기의 변경도 실시간으로 모달 초안에만 반영하고, 내부 버튼은
  `초안 반영`으로 표시해 DB 저장과 구분했다.
- 설명에서 제거한 기존 이미지는 특허 PATCH가 성공한 뒤에만 저장소에서 삭제하고,
  적용 전 업로드한 이미지는 모달 취소 시 정리한다.
- 특허 추가 모달은 기존처럼 로컬 초안을 `추가` 버튼으로 저장한다.

## 확인

- 즉시 저장 hook 참조와 필드별 저장 배지를 수정 모달에서 제거했다.
- 변경 감지는 API에 보내는 정규화된 값을 기준으로 비교하므로 공백만 다른 텍스트를
  변경으로 오인하지 않는다.
- 저장소 지침에 따라 빌드·실행은 수행하지 않았다.
