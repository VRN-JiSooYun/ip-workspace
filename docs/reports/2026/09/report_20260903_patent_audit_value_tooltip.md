# Patent audit 값 전체 보기

## 작업 목적

특허 상세의 활동 피드에서 변경 전·후 값이 220px 너비로 말줄임되어 전체 내용을 확인할 수
없는 문제를 해결한다.

## 변경 내용

- 감사 값을 공통 `AuditValue` 컴포넌트로 렌더링하도록 변경했다.
- `ResizeObserver`로 실제 overflow 여부를 확인해 잘린 값에만 원문 Tooltip을 제공한다.
- 마우스 hover뿐 아니라 키보드 focus로도 Tooltip을 열 수 있도록 잘린 값에 focus 진입점을
  추가했다.
- 긴 문장과 줄바꿈을 읽을 수 있도록 Tooltip 최대 폭·높이, 자동 줄바꿈과 세로 스크롤을
  설정했다.
- 변경 후 값뿐 아니라 동일한 문제가 있던 변경 전 값과 문서 연결 요약에도 같은 동작을
  적용했다.

## 검증 결과

- 값이 잘리지 않은 경우 불필요한 Tooltip과 focus 진입점이 생기지 않도록 확인했다.
- 기존 변경 전 값의 취소선과 변경 후 값의 강조 스타일을 유지했다.

## 미실행 항목

- 저장소 지침에 따라 빌드와 브라우저 실행은 수행하지 않았다.
