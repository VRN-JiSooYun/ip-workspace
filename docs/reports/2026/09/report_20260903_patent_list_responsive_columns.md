# Patent management 목록 컬럼 반응형 개선

## 작업 목적

Right Rail Panel을 열어 `pm-list-panel`의 가용 폭이 줄었을 때 고정 컬럼 폭 합계로 인해
가로 스크롤이 생기는 문제를 개선한다. 긴 텍스트는 공간에 맞춰 말줄임하고 원문 접근성은
Tooltip으로 유지한다.

## 변경 내용

- 관리 특허 목록 Table을 부모 폭에 맞추는 `fixed` 레이아웃으로 변경했다.
- `max-content` 가로 스크롤을 제거하고 컬럼 폭을 비율 단위로 재배분했다.
- `명칭`은 두 줄까지 표시한 뒤 말줄임하도록 변경했다.
- `출원인`, `대리인`은 한 줄 말줄임을 적용했다.
- `내부관리번호`는 줄바꿈과 말줄임 없이 원문을 유지하고, 해당 컬럼의 비율을 확대했다.
- `출원일`은 한 줄 말줄임을 적용하고 실제로 잘린 경우 전체 날짜 Tooltip을 제공한다.
- `ResizeObserver`로 실제 overflow 여부를 확인하여, 내용이 잘린 셀에만 원문 Tooltip이
  나타나도록 했다.
- 패널 폭이 줄어들어도 모든 컬럼을 유지하고, 비율 너비와 텍스트 말줄임으로 대응한다.
- `Target`을 목록의 첫 번째 컬럼으로 추가하고, 긴 값은 한 줄 말줄임과 원문 Tooltip으로
  표시한다.
- 셀 내부 콘텐츠가 컬럼 폭을 다시 밀어내지 않도록 overflow 경계를 추가했다.

## 검증 결과

- 정적 검토로 컬럼 너비 합계와 관리 권한별 액션 컬럼 구성을 확인했다.
- 빈 값은 기존과 동일하게 `-`로 표시되며 Tooltip을 만들지 않는다.
- 검색어 하이라이트 markup을 유지한 채 말줄임 래퍼 안에서 렌더링하도록 확인했다.

## 미실행 항목

- 저장소 지침에 따라 빌드와 브라우저 실행은 수행하지 않았다.
- 실제 Right Rail 열기·폭 조절에 따른 시각 검증은 로컬 개발 서버에서 확인이 필요하다.
