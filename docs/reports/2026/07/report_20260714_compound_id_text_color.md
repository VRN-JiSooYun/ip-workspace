# 물질 번호 컬럼 일반 텍스트 색상 통일

## 작업 내용

### MyBoard 그룹 상세 목록

- `물질 번호 (VRN)` 컬럼의 물질 코드는 기존 primary 강조색을 유지했다.
- 물질 코드가 아닌 비버튼 합성 상태 텍스트는 다른 테이블 컬럼과 동일한 테마 기본 본문색을 사용한다.
- `합성 요청` 버튼의 액션 색상은 유지했다.
- 클릭 가능한 `요청 완료` 텍스트 버튼은 동작과 hover 밑줄을 유지하면서 색상을 기본 본문색으로 통일했다.
- `요청 완료` 텍스트 버튼의 글자 크기를 다른 본문 컬럼과 맞게 `12px`로 조정했다.
- 물질 코드를 제외한 상태 텍스트의 font weight를 테이블 본문 기본 굵기인 `400`으로 변경했다.

### 합성 관리

- `물질 번호 (VRN)` 컬럼의 물질 코드는 기존 primary 강조색을 유지했다.
- 물질 코드가 아닌 합성 상태와 빈 값 표시는 다른 테이블 컬럼과 동일한 기본 본문색을 사용하도록 변경했다.
- 물질 코드를 제외한 상태 텍스트의 font weight를 테이블 본문 기본 굵기인 `400`으로 변경했다.
