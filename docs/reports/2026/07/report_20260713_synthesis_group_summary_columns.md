# 합성 관리 그룹 요약 컬럼 UX 변경

## 작업 내용

- 합성 관리 페이지 그룹 리스트의 요약 컬럼 순서를 `개수`, `합성 완료`, `합성 중`, `미배정`으로 변경했습니다.
- 개수는 흰색 배경과 검은색 글자, 합성 완료는 주황색, 합성 중은 파란색, 미배정은 회색으로 표시합니다.
- 숫자 표시는 기존 Ant Design Tag 형태를 유지하면서 상태별 배경색만 적용했습니다.
- 진한 단색 대신 테마 토큰 기반의 파스텔 배경, 상태색 글자 및 테두리 조합으로 변경했습니다.
- 모든 요약 Tag의 숫자 텍스트에 `font-weight: 700`을 적용했습니다.
- 합성 상태 배지의 담당자별 현황 Popover 동작은 유지했습니다.

## 확인 사항

- 실제 라우트인 `MyBoardSynthesisBoard`만 수정했습니다.
- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
