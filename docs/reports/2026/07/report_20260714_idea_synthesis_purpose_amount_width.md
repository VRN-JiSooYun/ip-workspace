# 아이디어 화합물 팝업 합성 정보 Data 영역 너비 조정

## 작업 내용

- `합성 목적`과 `필요량` label만 공통 `112px`에서 `72px`로 줄였다.
- `합성 확장필요 정도` label은 `합성 의뢰 비고`와 동일한 공통 `112px` 폭을 유지했다.
- 두 항목은 같은 50% 지점에서 시작하므로 label과 Data 시작 위치도 동일하게 유지된다.
- `합성 확장필요 정도` 컬럼 전체 폭을 `40px` 늘리고 인접한 `필요량` 컬럼 폭을 `40px` 줄였다.
- 이에 따라 합성 확장 Data 영역은 `40px` 넓어지고, 필요량은 줄어든 label 폭만큼 컬럼도 줄어 Data 시작 위치와 Data 너비가 기존과 동일하게 유지된다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
