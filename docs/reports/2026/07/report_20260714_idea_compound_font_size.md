# 아이디어 화합물 등록 팝업 글자 크기 통일

## 작업 내용

- 아이디어 화합물 등록·수정 팝업 폼의 기본 글자 크기를 `13px`로 통일했다.
- Form label, 입력값, placeholder, Select 선택값, 버튼, 디자인 비고 편집기 글자 크기에 공통 변수를 적용했다.
- Calculations 제목, 전체 선택 태그, 계산 항목 태그를 `13px`로 조정했다.
- 첨부파일 안내, 보조 안내, 파일 선택 버튼을 `13px`로 조정하고 안내 문구의 line-height를 함께 보정했다.
- 팝업으로 렌더링되는 Select·Cascader 항목과 내부 입력도 `13px`로 맞췄다.
- 팝업 제목은 정보 계층을 유지하기 위해 Ant Design의 기존 제목 크기를 유지했다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
