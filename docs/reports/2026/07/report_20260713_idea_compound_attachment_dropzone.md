# 아이디어 화합물 첨부파일 드롭존 UX 수정

## 작업 내용

- My Board 아이디어 화합물 등록/수정 팝업의 첨부파일 입력을 점선 테두리의 드래그 앤 드롭 영역으로 변경했습니다.
- `sample/ui/drag_and_drop.png`를 기준으로 큰 안내 문구, 보조 문구, 작은 파일 선택 버튼을 드롭존 중앙에 세로로 배치했습니다.
- 드롭존에서 파일을 끌어 놓거나 `파일 선택` 버튼을 눌러 파일을 추가할 수 있습니다.
- 안내 영역의 너비와 정렬 기준을 드롭존 전체로 맞췄으며, 파일이 첨부되면 안내 문구와 선택 버튼을 숨기고 파일 목록만 표시합니다.
- Ant Design 내부 업로드 버튼 컨테이너까지 전체 너비의 flex 중앙 정렬을 적용해 안내 영역이 점선 박스의 가로 중앙에 위치하도록 보정했습니다.
- `파일 선택` 버튼의 border-radius를 팝업 입력 요소와 동일한 값으로 통일했습니다.
- 첨부된 파일 목록을 점선 드롭존 내부에 표시해 파일 목록이 나타난 전체 영역에서도 파일을 추가로 드롭할 수 있습니다.
- 다중 파일 첨부와 개별 파일 삭제를 지원하며, 첨부 파일이 많을 때 내부 목록을 스크롤할 수 있습니다.
- 팝업을 닫거나 등록/수정을 완료하면 임시 첨부 목록을 초기화합니다.

## 검증

- 정적 코드 및 diff 형식을 확인했습니다.
- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
