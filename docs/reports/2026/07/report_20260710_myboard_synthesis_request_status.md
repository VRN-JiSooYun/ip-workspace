# MyBoard 합성 요청 상태 표시 구현

## 변경 내용
- `frontend/src/mocks/compounds.ts`
  - `Compound` 타입에 합성 요청 상태 필드를 추가했다.
    - `synthesisRequestStatus`
    - `synthesisRequestType`
    - `synthesisStep`
  - `compoundId`가 없는 mock row 일부에 `요청 완료`, `접수 완료`, `합성중` 표시용 상태를 추가했다.
- `frontend/src/pages/MyBoard.tsx`
  - 새 컬럼을 추가하지 않고 기존 `물질 번호 (VRN)` 컬럼에서 상태를 렌더링하도록 변경했다.
  - `compoundId`가 있는 row는 기존처럼 물질 번호만 표시한다.
  - `compoundId`가 없는 row는 상태에 따라 다음 UI를 표시한다.
    - 요청 전: `합성 요청` 버튼
    - 요청 완료: `요청 완료` 버튼
    - 접수 완료: `접수 완료` tag
    - 합성중: `합성중` tag
  - 합성 요청 버튼 클릭 시 `화합물 합성 요청` Modal을 표시하도록 추가했다.
  - Modal은 첨부 이미지 기준으로 상단 구조/기본정보, 하단 요청 입력 영역으로 구성했다.
  - Modal 상단 화합물 구조 영역을 키워 우측 디자인 비고 영역 끝선과 맞췄다.
  - Modal 상단 화합물 구조 action 버튼 영역을 구조 프레임 하단 우측 overlay로 배치했다.
  - Modal 상단 디자인 비고를 textarea 대신 그룹 상세 목록의 디자인 비고 컬럼과 같은 preview renderer로 표시하도록 변경했다.
  - Modal의 `합성 목적`을 아이디어 화합물 등록 팝업과 같은 다중 Cascader로 변경했다.
  - Modal의 `합성 목적`에서 `레퍼런스` 선택 시 아이디어 화합물 등록 팝업과 같은 하위 입력 패널이 표시되도록 수정했다.
  - Modal의 `단계`를 아이디어 화합물 등록 팝업의 `합성 확장필요 정도`와 같은 다중 Cascader로 변경했다.
  - `요청 완료` 버튼으로 Modal을 열면 입력값을 수정할 수 없는 조회 전용 모드로 표시되도록 변경했다.
  - 조회 전용 Modal에서는 footer의 `요청` 버튼 대신 `요청 취소` 버튼을 표시하도록 변경했다.
  - 조회 전용 Modal의 `디자인 비고`, `기대 개선 효과`, `비고` preview 내용을 좌측 정렬로 보정했다.
  - Modal 상단 `디자인 비고` preview 내용을 세로 중앙이 아니라 상단부터 표시하도록 보정했다.
  - 합성 요청 Modal footer의 보조 버튼 문구를 `취소`에서 `닫기`로 변경했다.
  - 필수 입력값이 충족될 때만 `요청` 버튼이 활성화되도록 처리했다.
  - 그룹 상세 목록의 Table view와 그룹 리스트는 기존 높이 동작을 유지하고, Canvas/Tree view에만 MyBoard main 영역의 남은 높이를 채우는 flex fill 구조를 적용했다.
  - 기존 `progressMemo`가 실제 의뢰 번호 형식(`LYH-YY-0000`)일 때만 합성 의뢰 번호로 재사용하도록 보정했다.
  - MyBoard 내 실제 동작은 `요청 완료` 저장과 `요청 취소`까지만 구현했다.
  - `접수 완료 -> 합성중 -> VNA코드` 전환은 향후 합성 보드에서 처리하는 전제로 mock 표시만 지원한다.

## 확인 필요
- 로컬 실행은 사용자가 진행한다.
- 그룹 상세 목록에서 물질 번호가 있는 row는 상태/버튼 없이 VNA 코드만 표시되는지 확인한다.
- `compoundId`가 없는 row에서 `합성 요청` 버튼이 보이고, 클릭 시 Modal이 열리는지 확인한다.
- Modal 필수값 입력 전/후 `요청` 버튼 활성화 상태를 확인한다.
- 요청 완료 후 `물질 번호 (VRN)` 셀에 `요청 완료` 버튼이 표시되고, 조회 전용 Modal에서 `요청 취소`가 가능한지 확인한다.
- 취소 후 다시 `합성 요청` 버튼이 표시되는지 확인한다.
