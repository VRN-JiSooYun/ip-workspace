# MyBoard 그룹 리스트 컬럼 폭 조정

## 요청
- MyBoard 페이지 그룹 리스트의 `Date`, `개수`, `그룹`, `공유` 컬럼 폭을 줄인다.

## 변경
- `frontend/src/pages/MyBoard.tsx`
  - 그룹 리스트 고정 컬럼 폭 상수 조정:
    - `Date`: 100px -> 82px
    - `개수`: 60px -> 48px
    - `그룹`: 52px -> 38px
    - `공유`: 56px -> 38px
  - 같은 상수가 그룹 리스트 자동 폭 계산에도 사용되므로 전체 그룹 패널 기본 폭도 함께 줄어든다.

## 검증
- 로컬에는 Bun/npm이 없고 빌드는 사용자가 수행한다는 프로젝트 지침에 따라 빌드는 실행하지 않았다.
