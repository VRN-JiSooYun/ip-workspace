# MyBoard 메모 입력 안내 문구 수정

## 변경 내용

- MyBoard 디자인 등록·수정 팝업의 `기대 개선 효과` 입력 영역 placeholder를 `내용 입력 (이미지 첨부 가능)`으로 변경했다.
- `합성 의뢰 비고` 입력 영역에도 같은 placeholder를 적용했다.
- `디자인 비고` 입력 영역에도 같은 placeholder를 적용했다.
- MyBoard 디자인 등록·수정 팝업의 ChemDraw 높이를 `360px`에서 `432px`로 변경해 기존 대비 120%로 확대했다.
- 디자인 비고, 기대 개선 효과, 합성 의뢰 비고 편집 영역의 높이를 약 3줄 분량인 `64px`로 축소하고 초과 내용은 내부 스크롤로 확인하도록 유지했다.

## 검증 결과

- 세 `PlainMemoEditor`에 동일한 안내 문구가 적용됐는지 소스 검색으로 확인했다.
- `git diff --check`로 변경 파일의 공백 오류를 확인했다.

## 미실행 항목

- 프로젝트 지침에 따라 빌드와 실행은 수행하지 않았다.
