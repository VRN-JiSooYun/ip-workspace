# My Board 그룹 리스트 핀 필터 작업 보고서

## 작업 내용
- My Board 페이지의 그룹 리스트 헤더에 `전체 보기 / 핀 고정` 필터 컨트롤을 추가했다.
- 기존 핀 고정 상태인 `bookmarkedGroupIds`를 기준으로 그룹 리스트 필터를 구성했다.
- `핀 고정` 선택 시 핀 고정된 그룹만 그룹 리스트 테이블에 표시한다.
- 핀 고정 그룹이 없을 때는 `핀 고정된 그룹이 없습니다.` 빈 상태 문구를 표시한다.

## 구현 기준
- 그룹 정렬은 기존과 동일하게 핀 고정 그룹을 상단에 배치한다.
- 필터는 그룹 리스트 표시 범위에만 적용하고, 사용자가 이미 선택한 그룹 상세 목록은 강제로 초기화하지 않는다.

## 2026-07-06 추가 반영
- My Board 그룹 리스트의 핀 고정 상태를 공용 board store로 이동했다.
- SAR Table의 좌측 화합물 구조 영역은 My Board 그룹 리스트의 대표 구조 영역과 같은 고정 UX로 취급한다.
- My Board에서 핀 고정한 그룹은 SAR Table 좌측 화합물 구조 영역에서도 핀 고정 상태로 표시하고 상단 정렬한다.
- 현재는 backend/DB가 없으므로 UX 확인용으로 `localStorage` key `my-board:bookmarked-group-ids`에 임시 저장한다.

## DB 전환 시 주의
- 추후 backend와 DB로 그룹 핀 고정 상태를 저장하게 되면 `localStorage` key `my-board:bookmarked-group-ids`는 제거하거나 초기화해야 한다.
- DB 데이터가 기준이 되는 시점에는 클라이언트 임시 저장값이 서버 상태를 덮어쓰지 않도록 store 초기화 로직을 정리해야 한다.
