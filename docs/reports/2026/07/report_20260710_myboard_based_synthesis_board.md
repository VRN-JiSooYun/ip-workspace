# MyBoard 기반 합성 보드 페이지 생성

## 변경 내용
- `frontend/src/pages/MyBoardSynthesisBoard.tsx`
  - `MyBoard.tsx`를 기반으로 새 합성 보드 페이지를 추가했다.
  - 기존 `SynthesisBoard.tsx`의 담당자별 합성 현황 hover popup UI를 새 페이지에 이식했다.
  - 그룹 리스트의 `개수` 컬럼과 `그룹` 컬럼 사이에 `합성중`, `합성완료`, `미배정` 컬럼을 추가했다.
  - 각 합성 현황 컬럼 hover 시 담당자별 합성 현황 popup이 표시되도록 연결했다.
  - 그룹 리스트 헤더의 `합성 보드` 버튼을 `돌아가기` 버튼으로 교체하고 `/myboard`로 이동하도록 변경했다.
  - `돌아가기` 버튼은 Design 페이지의 `합성 관리` 버튼과 동일한 크기, 높이, padding, 강조 두께 UX를 사용하도록 맞췄다.
  - 그룹 리스트 헤더의 `Add Group` 버튼을 제거했다.
  - 그룹 상세 목록 toolbar는 `데이터 컬럼 설정` 버튼만 남기고 추가/삭제/수정/필터/뷰 전환/구조 스케일 기능 버튼을 제거했다.
  - 그룹 상세 목록의 `물질 번호 (VRN)` 컬럼은 합성 요청 버튼 없이 물질 번호 또는 상태 tag만 표시하도록 변경했다.
  - 그룹 상세 목록 기본 컬럼은 `디자인 비고` 다음부터 기존 합성 보드의 합성 상세 컬럼(`합성 담당자`부터 `합성 종료 이유`까지)이 표시되도록 변경했다.
  - 합성 현황 hover popup은 그룹 상세 목록의 실제 `합성 담당자` mock 데이터 기준으로 담당자별 합성중/완료 건수를 집계하도록 변경했다.
  - 그룹 리스트 `Title` 컬럼 UX를 Design 페이지와 동일하게 맞춰 최소 width, 4줄 말줄임, 초기 패널 폭, horizontal scroll 판정을 보정했다.
  - 합성 보드의 좌우/상하 stacked 레이아웃 전환 기준을 `1500px`로 변경했다.
  - 합성 보드 페이지 상단 헤더를 `Design > 합성 관리` 브레드크럼으로 표시하도록 변경했다.
- `frontend/src/App.tsx`
  - `/synthesis`와 `/myboard/synthesis-board`가 새 `MyBoardSynthesisBoard` 페이지를 사용하도록 라우팅을 변경했다.
  - 기존 `SynthesisBoard.tsx` 파일은 보존했다.

## 확인 필요
- `/myboard/synthesis-board`와 `/synthesis` 진입 시 새 MyBoard 기반 합성 보드가 표시되는지 확인한다.
- 그룹 리스트에서 `개수`, `합성중`, `합성완료`, `미배정`, `그룹` 컬럼 순서가 맞는지 확인한다.
- 합성 현황 컬럼 hover popup이 기존 합성 보드와 같은 형태로 표시되는지 확인한다.
- 그룹 상세 목록 toolbar에 `데이터 컬럼 설정`만 남아 있는지 확인한다.
- `물질 번호 (VRN)` 컬럼에 합성 요청/요청 완료 버튼이 보이지 않고 물질 번호 또는 tag만 표시되는지 확인한다.
- 그룹 상세 목록에서 `디자인 비고` 바로 다음 컬럼이 `합성 담당자`인지 확인한다.
- 합성 현황 hover popup의 담당자 목록과 합계가 그룹 상세 목록의 `합성 담당자` mock 데이터와 일치하는지 확인한다.
- 합성 보드 그룹 리스트 `Title` 컬럼이 Design 페이지와 동일하게 4줄 말줄임 및 초기 가로 스크롤 억제 UX로 동작하는지 확인한다.
- 합성 보드가 화면 폭 `1500px` 이하에서 그룹 리스트와 그룹 상세 목록을 상하 배치로 전환하는지 확인한다.
- 합성 보드 페이지 상단 헤더가 `Design > 합성 관리`로 표시되는지 확인한다.
