# 화합물 합성 요청 팝업 입력 UX 통일

## 작업 내용

- 화합물 합성 요청 팝업의 Input, InputNumber, Select/Cascader에 현재 Ant Design 입력 필드의 테마 `borderRadius`를 공통 적용했습니다.
- 구조 미리보기 프레임, 디자인 비고 및 읽기 전용 메모 박스, 메모 입력 에디터도 같은 radius로 통일했습니다.
- 스타일 적용 범위를 `.synthesis-request-modal`과 `.synthesis-request-form` 내부로 제한했습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
