# SAR 카드 회전 시 구조 배율 고정

## 작업 내용

- SAR 우측 화합물 카드의 정사각형 구조 프레임은 유지했다.
- 각 화합물의 최초 유효 RDKit SVG 크기를 표시 baseline으로 보존하고, 0도 SVG 캐시가 있으면 이를 우선 사용한다.
- 전체 화합물 baseline의 최대 대각선 길이를 기준으로 공통 표시 scale을 계산한다.
- 회전 후 SVG의 width와 height는 새 canvas 비율에 맞게 반영하되, 공통 표시 scale은 회전 결과로 다시 계산하지 않는다.
- cluster highlight SVG에도 동일한 baseline scale을 적용한다.

## 기대 결과

- 회전값이 변경되어 SVG canvas의 가로세로 비율이 달라져도 원자, 결합선, 라벨의 화면 배율이 유지된다.
- 회전된 구조는 정사각형 프레임 중앙에 배치되며 대각선 기준으로 프레임 안에 표시된다.

## 확인 사항

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
- 브라우저에서 0도, 30도, 60도, 90도 회전 시 동일 구조의 원자와 결합선 크기가 유지되는지 확인이 필요하다.
