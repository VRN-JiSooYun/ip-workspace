# MyBoard 그룹 상세 Toolbar 간격 통일

## 작업 내용

- MyBoard 그룹 상세 목록 Toolbar의 항목 간격을 SAR Table 우측 화합물 카드 영역 Toolbar 기준과 동일한 `8px`로 통일했다.
- 그룹 상세 제목과 액션 영역 사이 간격을 `16px`에서 `8px`로 변경했다.
- 액션 버튼 그룹과 `Show` 필터 사이 간격을 `16px`에서 `8px`로 변경했다.
- `Quick add`, `Add`, `Edit`, `Del`, `숨기기` 버튼 사이 간격은 이미 SAR 기준과 같은 `8px`이므로 유지했다.
- 오른쪽 Scale 및 보기 설정 영역의 `8px`, 내부 조절 버튼의 `4px` 간격도 이미 SAR 기준과 같아 유지했다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
