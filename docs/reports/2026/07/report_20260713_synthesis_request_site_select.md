# 화합물 합성 요청 수행처 선택

## 작업 내용

- MyBoard 화합물 합성 요청 팝업에 `선택 항목` 단일 선택 필드를 추가했습니다.
- 선택 옵션은 `In-house`, `Wuxi`입니다.
- 해당 필드는 선택 사항이며 값을 고르지 않아도 합성 요청을 진행할 수 있습니다.
- 선택값을 Compound 데이터의 `synthesisSite`에 저장하고 팝업을 다시 열 때 복원하도록 연결했습니다.
- 기존 `합성 요청 구분`은 요청 유형을 나타내므로 별도 필드로 유지했습니다.
- RDKit 및 `rdkit/`, `compound_search/` API 구현은 수정하지 않았습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
