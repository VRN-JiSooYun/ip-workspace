# My Board Show filter 활성 색상 변경

## 작업 내용

- My Board 그룹 상세 목록 Toolbar의 Show filter에서 활성화된 항목의 배경을 파스텔 하늘색으로 변경했다.
- 활성 항목의 테두리와 글자색도 Ant Design Info 계열 색상으로 맞췄다.
- Segmented 전환 애니메이션의 thumb에도 같은 배경과 테두리를 적용했다.
- Ant Design 테마 토큰을 사용해 라이트·다크 모드에서 적절한 대비가 유지되도록 했다.
- My Board Show filter 전용 selector를 사용해 SAR Table과 다른 Segmented 컴포넌트에는 영향을 주지 않는다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
