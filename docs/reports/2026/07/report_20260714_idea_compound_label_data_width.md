# 아이디어 화합물 등록 팝업 label 및 Data 영역 너비 조정

## 작업 내용

- 아이디어 화합물 등록·수정 팝업의 공통 label 컬럼 폭을 `132px`에서 `112px`로 줄였다.
- 줄어든 `20px`를 입력, 선택, Calculations 등 우측 Data 영역에서 사용할 수 있도록 기존 `minmax(0, 1fr)` 구조를 유지했다.
- 가장 긴 label인 `합성 확장필요 정도`가 한 줄로 표시될 수 있는 폭을 기준으로 조정했다.
- 다른 팝업과 일반 Form에는 영향을 주지 않도록 `.idea-compound-modal` 전용 CSS 변수만 변경했다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
