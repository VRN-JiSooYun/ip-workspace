# 그룹 상세 목록 툴바 배치 변경

## 작업 내용

- 그룹 상세 목록의 행 작업 버튼을 `Quick add`, `Add`, `Edit`, `Del`, `숨기기` 순서로 재배치했습니다.
- 행 작업 버튼 뒤에 16px 간격을 두고 `Show All / Compound / Design` 필터를 배치했습니다.
- 필터는 SAR Table의 하이라이팅 설정과 동일한 라벨 + Segmented 단일 선택 UX로 변경했습니다.
- `Show` 필터 외곽의 `border-radius`는 같은 툴바의 `Scale` 설정과 동일한 `6px`로 맞췄습니다.
- `숨기기` 작업 버튼 그룹과 `Show` 필터 사이 간격 중앙에 세로 구분선을 추가했습니다.
- 작업 버튼과 필터 버튼을 별도 그룹으로 묶어 좁은 화면에서 줄바꿈되더라도 그룹 단위가 유지되도록 했습니다.
- 각 버튼의 기존 활성화 조건과 클릭 동작은 변경하지 않았습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
