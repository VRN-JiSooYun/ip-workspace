# SAR Table 설정 Segmented 활성 색상 변경

## 작업 내용

- SAR Table 우측 화합물 카드 Toolbar의 Atom, Abbreviation, Highlight, Show 활성 항목을 파스텔 하늘색으로 변경했다.
- 활성 항목의 배경, 테두리, 글자색과 Segmented 전환 thumb에 Ant Design Info 계열 테마 토큰을 적용했다.
- 라이트·다크 모드에서 적절한 대비가 유지된다.
- 네 설정이 공유하는 `.sar-compound-highlight-toggle` 범위로 제한해 다른 페이지의 Segmented에는 영향을 주지 않는다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
