# Design 그룹 상세 합성 상태 텍스트 UX

## 작업 내용

- Design 페이지 그룹 상세 목록의 물질 번호 컬럼에서 합성 상태의 Tag와 pill button 스타일을 제거했다.
- `접수 완료`, `합성중`, `VNA코드`는 배경과 테두리 없이 상태 색상만 적용한 텍스트로 표시한다.
- `요청 완료`는 합성 요청 상세/취소 동작을 유지하면서 일반 텍스트처럼 보이는 semantic button으로 변경했다.
- 실제 명령인 `합성 요청` 버튼은 기존 button 스타일을 유지한다.
- Synthesis Board 그룹 상세 목록에도 동일한 텍스트 UX를 적용했다.
- Synthesis Board의 `요청 완료`, `접수 완료`, `합성중`, `VNA코드`는 클릭 동작 없이 상태 색상 텍스트로 표시한다.

## 확인 사항

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
- 상태 텍스트가 버튼이나 Tag처럼 보이지 않는지와 `요청 완료` 클릭 동작을 브라우저에서 확인할 필요가 있다.
