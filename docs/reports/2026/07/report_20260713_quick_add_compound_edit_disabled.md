# Quick add 화합물 편집 비활성화

## 작업 내용

- Quick add를 통해 `compound_api`에서 추가된 VRN 화합물 행은 단일 선택해도 수정할 수 없도록 변경했습니다.
- Mock 데이터의 `VNA-...`, `VNA240...` 등 `VNA` 접두 물질 번호도 수정할 수 없도록 처리했습니다.
- 상단 `Edit` 버튼과 행 우클릭 메뉴의 `수정` 항목이 동일한 활성화 조건을 사용하므로 두 진입점이 모두 비활성화됩니다.
- 삭제, 숨기기, 그룹 이동 및 복제 등 다른 행 동작은 기존대로 유지됩니다.
- 외부 API 구현이나 `compound_search/` 영역은 수정하지 않았습니다.

## 실 데이터 전환

- 편집 잠금 판정을 `isCompoundEditLocked` 함수로 분리했습니다.
- 실 API가 화합물 출처 메타데이터를 항상 제공하게 되면 함수 내부의 `VNA` 접두사 Mock 호환 조건만 제거하고 `externalSource` 판정을 유지하면 됩니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
