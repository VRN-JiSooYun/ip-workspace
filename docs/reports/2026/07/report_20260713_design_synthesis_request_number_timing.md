# Design 합성 의뢰 번호 생성 시점 변경

## 작업 내용

- 아이디어 화합물 등록 팝업을 열 때 합성 의뢰 번호를 미리 생성하지 않도록 변경했다.
- 아이디어 화합물 등록 시 합성 의뢰 번호 counter를 예약하지 않고 `progressMemo`를 `-`로 저장한다.
- 그룹 상세 목록에서 `합성 요청` 팝업을 열 때 다음 합성 의뢰 번호를 자동 표시하는 기존 동작을 유지했다.
- 실제 합성 요청 제출 시에만 합성 의뢰 번호 counter를 예약하고 해당 번호를 화합물에 저장한다.
- 아이디어 등록 팝업과 합성 요청 팝업의 합성 의뢰 번호 입력은 모두 기존처럼 disabled 상태를 유지한다.
- 디자인 form store를 modal reset 시 함께 초기화해 이전 편집 번호가 신규 등록 팝업에 남지 않도록 했다.

## 확인 사항

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
- 아이디어 등록 시 번호가 비어 있고, 등록 후 합성 요청 팝업에서 다음 번호가 자동 표시되는지 브라우저 확인이 필요하다.
