# 화합물 합성 요청 기대 개선 효과 필수화

## 작업 내용

- MyBoard 화합물 합성 요청 팝업의 `기대 개선 효과`를 필수 입력 항목으로 변경했습니다.
- 실제 텍스트나 이미지가 없는 빈 HTML(`<p><br></p>` 등)은 입력되지 않은 값으로 판정합니다.
- 기대 개선 효과가 비어 있으면 요청 버튼이 활성화되지 않으며, Form 검증에서도 안내 메시지를 표시합니다.
- 이미 요청된 화합물을 확인하는 읽기 전용 상태에는 영향을 주지 않습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
