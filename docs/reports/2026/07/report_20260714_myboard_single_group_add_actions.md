# MyBoard 단일 그룹 Add 액션 활성화

## 작업 내용

- MyBoard 그룹 리스트에서 선택된 그룹이 정확히 1개일 때만 `Quick add`, `Add` 버튼이 활성화되도록 변경했다.
- 선택 그룹이 없거나 2개 이상이면 두 버튼을 비활성화한다.
- Quick Add 모달의 확인 버튼, Enter 처리, 실제 추가 핸들러에도 동일한 단일 그룹 조건을 적용했다.
- Add 등록 핸들러에도 동일한 조건을 적용해 UI 상태 외의 경로로 다중 그룹 등록이 실행되지 않도록 했다.

## 검증 기준

- 그룹 0개 선택: `Quick add`, `Add` 비활성화
- 그룹 1개 선택: `Quick add`, `Add` 활성화
- 그룹 2개 이상 선택: `Quick add`, `Add` 비활성화

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
