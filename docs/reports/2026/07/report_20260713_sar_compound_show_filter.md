# SAR Table 화합물 Show 필터

## 작업 내용

- SAR Table 화합물 카드 툴바의 Highlight 영역 우측에 `Show` 필터를 추가했습니다.
- 툴바 기본 간격 8px에 추가 여백 12px을 적용해 Highlight 영역과 20px 떨어지도록 배치했습니다.
- Highlight와 Show 사이의 20px 간격 중앙에 세로 구분선을 추가했습니다.
- 필터 옵션은 `All`, `Compound`, `Design`이며 물질 번호 존재 여부를 기준으로 화합물과 디자인을 구분합니다.
- 필터 결과를 화합물 카드와 연결된 SAR 테이블 데이터에 함께 적용하고, 표시 개수도 필터 결과에 맞췄습니다.
- 툴바가 좁아질 때 컨트롤이 겹치지 않도록 좌측 툴바 영역의 줄바꿈을 허용했습니다.
- RDKit 및 `rdkit/`, `compound_search/` API 구현은 수정하지 않았습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
