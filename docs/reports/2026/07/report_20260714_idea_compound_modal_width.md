# 아이디어 화합물 팝업 폭 조정

## 작업 내용

- 아이디어 화합물 등록/수정 팝업의 최대 폭을 `1,440px`에서 `1,200px`로 축소했다.
- 기존에 팝업 내부 폭의 `80%`만 사용하던 ChemDraw 구조 영역을 축소된 팝업의 가용 폭 `100%`로 조정했다.
- 구조 영역 아래 SMILES 입력의 오른쪽 `20%` 여백을 제거해 ChemDraw 영역의 오른쪽 끝과 정렬했다.
- 작은 화면에서는 기존처럼 `calc(100vw - 24px)` 제한을 유지해 viewport를 벗어나지 않도록 했다.

## 결과

- 기존 ChemDraw 구조 영역과 비슷한 실사용 폭을 유지하면서 팝업 우측의 불필요한 공간을 줄였다.
- 등록과 수정 팝업에 동일하게 적용된다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
