# 합성 관리 합성 중단 컬럼 추가

## 작업 목적

합성 관리 페이지의 그룹 목록에서 미배정 컬럼 오른쪽에 합성 중단 현황을 확인할 수 있는 컬럼을 추가한다.

## 변경 내용

- `미배정` 바로 오른쪽에 `합성 중단` 고정 너비 컬럼을 추가했다.
- 합성 중단 집계 배지에 Ant Design Error 계열 배경, 테두리, 텍스트 색상을 적용했다.
- `status`가 `합성 중단`이거나, 완료되지 않은 항목에 `합성 종료 이유`가 입력된 경우 합성 중단으로 분류한다.
- 합성 중단 항목은 완료, 진행 중, 미배정 집계에서 제외해 중복 집계되지 않도록 했다.
- 담당자별 합성 현황 팝업에도 중단 컬럼과 빨간색 수치를 추가했다.
- 그룹 목록의 고정 폭 계산에 합성 중단 컬럼 너비를 포함했다.

## 검증 결과

- 그룹 컬럼 순서에서 `미배정` 다음에 `합성 중단`이 배치되는 것을 코드에서 확인했다.
- 합성 중단 수가 그룹 상태와 담당자 상태에 각각 집계되는 것을 확인했다.
- 중단 여부를 다른 상태보다 먼저 판정해 상태별 수치가 중복되지 않는 것을 확인했다.

## 미실행 항목

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
