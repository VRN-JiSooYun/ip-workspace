# 합성 요청 기능 SynthesisBoard 이전

## 작업 목적

- MyBoard 그룹 상세 목록의 물질 번호 컬럼에 있던 합성 요청 진입점과 팝업을 SynthesisBoard 그룹 상세 목록으로 이전한다.
- MyBoard에서 물질 번호가 없는 행은 버튼이나 상태 문구 없이 빈 셀로 표시한다.

## 변경 내용

- 실제 합성 관리 라우트인 `MyBoardSynthesisBoard`에 합성 의뢰 번호 생성, 합성 목적·단계·필요량·기대 개선 효과·비고·요청 구분 입력과 필수값 검증 흐름을 연결했다.
- 요청 완료 상태에서 팝업을 읽기 전용으로 다시 열고 요청을 취소하는 흐름을 이전했다.
- SynthesisBoard 그룹 상세 목록의 물질 번호 컬럼에서 물질 번호가 없는 행에 `합성 요청` 버튼을 표시한다.
- 요청 완료 후 같은 셀에 `요청 완료`를 표시하고 클릭하면 입력 내용을 확인하거나 요청을 취소할 수 있게 했다.
- 요청 결과는 합성 관리 페이지의 compound row 상태에 반영해 페이지가 유지되는 동안 Table과 팝업이 같은 값을 사용하도록 했다.
- 기존 합성 담당자 배정 팝업은 유지하고 제목을 `합성 담당자 배정`으로 명확히 구분했다.
- MyBoard 물질 번호 셀은 접수 전에는 빈 값을 표시하고, 접수 이후에는 현재 합성 상태를 표시하도록 변경했다.
- MyBoard에서 합성 요청 팝업 렌더링을 제거했다.
- MyBoard에 남아 있던 합성 요청 전용 form 상태, 요청 번호 helper, 제출·취소 handler와 전용 CSS를 제거했다.
- 합성 요청 코드와 인접한 공통 compound action 버튼 스타일 helper는 유지해 SAR Table 이동 및 상세 action 버튼 렌더링이 정상 동작하도록 했다.
- 물질 번호 컬럼의 상태 라벨을 `접수 대기 → 합성 대기 → 합성 중 → VNA 코드`로 통일했다.
- MyBoard는 접수 전 빈 셀을 유지하고 상태가 생긴 뒤부터 라벨을 표시하며, SynthesisBoard는 접수 전 `합성 요청` 버튼을 표시한다.
- 실제 VNA 물질 번호가 발급된 행은 상태 라벨보다 실제 물질 번호를 우선 표시한다.
- 물질 번호의 기존 미입력 표기 `-`는 빈값과 동일하게 처리해 MyBoard에서는 빈 셀로, SynthesisBoard에서는 `합성 요청` 버튼으로 표시한다.
- MyBoard 물질 번호 컬럼의 합성 상태 라벨 글자 크기를 `12px`로 조정했다.
- 실제 합성 관리 라우트가 사용하는 `MyBoardSynthesisBoard`의 물질 번호 빈값 및 `-` 표기를 `합성 요청` 버튼으로 변경하고 기존 요청 팝업을 연결했다.
- 라우트에서 사용하지 않는 구형 `pages/SynthesisBoard.tsx` 파일을 삭제했다.
- MyBoard mock compound에 접수 전, 접수 대기, 합성 대기, 합성 중, VNA 발급 상태가 반복되도록 seed 상태 매핑을 보강했다.

## 검증 결과

- 실제 합성 관리 라우트가 `MyBoardSynthesisBoard`를 렌더링하는지 확인했다.
- MyBoard 물질 번호 렌더러가 접수 전에는 빈 값을, 접수 이후에는 매핑된 상태 라벨을 반환하는지 확인했다.
- MyBoard에서 사용하는 `getCompoundActionButtonStyle` 정의와 모든 호출부가 함께 존재하는지 확인했다.
- 합성 관리 페이지의 요청·요청 완료 재열기 이벤트가 행 클릭으로 전파되지 않도록 확인했다.
- `git diff --check`로 변경 파일의 공백 오류를 확인했다.

## 미실행 항목

- 프로젝트 지침에 따라 빌드와 실행은 수행하지 않았다.
- 브라우저에서 합성 요청 등록, 요청 완료 재열기, 요청 취소, 담당자 배정 팝업 회귀를 확인해야 한다.
