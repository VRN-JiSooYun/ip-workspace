# 화합물 합성 요청 팝업 레이아웃 및 옵션 변경

## 작업 내용

- 합성 의뢰 번호와 필요량 영역을 각각 `8/24` 폭으로 줄였다.
- 합성 목적과 단계 영역을 각각 `16/24` 폭으로 늘렸다.
- 아이디어 화합물 등록 팝업의 합성 의뢰 번호 입력 영역과 유사한 실제 입력 폭이 되도록 두 팝업의 전체 폭 및 label 폭 차이를 반영했다.
- `합성 요청 구분` 옵션을 기존 `신규 합성`, `재합성` 등의 목록에서 `In-house`, `Wuxi`로 교체했다.
- 별도의 `선택 항목` 영역을 제거했다.
- `합성 요청 구분` 영역을 필요량과 동일한 `8/24` 폭으로 조정했다.
- 선택한 합성 요청 구분은 기존 `synthesisRequestType`에 저장하고 호환성을 위해 `synthesisSite`에도 동일하게 반영한다.
- 기존 요청을 열 때는 `synthesisSite` 값을 우선 표시하고, 값이 없으면 `synthesisRequestType`을 사용한다.
- 팝업 폭을 `760px`에서 `880px`로 늘려 우측 디자인 비고 표시 영역의 실사용 폭을 기존 대비 약 150%로 확장했다.
- 화합물 구조 영역의 고정 폭은 유지하고 늘어난 팝업 폭을 우측 요약 영역에 배분했다.

## 실행 여부

- 프로젝트 지침에 따라 빌드 및 실행은 수행하지 않았다.
