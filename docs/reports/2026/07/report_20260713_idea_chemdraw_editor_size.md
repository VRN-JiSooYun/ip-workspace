# 아이디어 화합물 ChemDraw 편집기 크기 조정

## 작업 내용

- 아이디어 화합물 등록/수정 팝업의 ChemDraw 편집기 영역 가로 폭을 기존 대비 `80%`로 조정했습니다.
- 편집기 높이를 `300px`에서 `360px`로 변경해 기존 대비 `120%`로 확대했습니다.
- 좌측 도구 버튼과 캔버스를 전용 래퍼로 묶어 함께 크기가 조정되도록 했습니다.
- SMILES 입력 영역의 오른쪽 끝을 ChemDraw 영역의 80% 폭에 맞추고, 왼쪽은 기존처럼 도구 버튼 다음의 캔버스 시작점에 정렬했습니다.
- 변경 범위를 아이디어 화합물 등록/수정 팝업으로 제한했습니다.

## 확인 사항

- 저장소 지침에 따라 빌드 및 실행은 수행하지 않았습니다.
