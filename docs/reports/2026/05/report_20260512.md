# PDF Worker/Viewer 로딩 에러 대응 (2026-05-12)

## 증상 1
- 배포(dev) 환경에서 PDF 로더 진입 시 아래 에러 발생
- `Setting up fake worker failed: "Failed to fetch dynamically imported module: http://<host>/assets/pdf.worker.min-<hash>.mjs"`
- 브라우저 콘솔: `.mjs` 응답 MIME이 `application/octet-stream`

## 원인 1
- Nginx가 `pdf.worker.min-*.mjs`를 JavaScript 모듈 MIME이 아닌 `application/octet-stream`으로 응답함
- 브라우저 strict MIME checking 때문에 module script 로딩 차단

## 증상 2
- `Error: The container must be absolutely positioned.`

## 원인 2
- `react-pdf-highlighter-plus`가 요구하는 컨테이너 레이아웃 조건(`absolute`) 미충족

## 적용 조치
1. `PatentPdfViewer.tsx`
- worker를 `pdf.worker.min.mjs?url`로 명시
- `pdfjs.GlobalWorkerOptions.workerSrc` 설정
- `window.pdfjsLib.GlobalWorkerOptions.workerSrc` 동기화
- viewer 루트 div에 `position: relative` 추가

2. `PatentPdfRenderer.tsx`
- `PdfHighlighter` style을 `position: absolute; inset: 0; overflow: auto`로 변경

3. `nginx.conf`
- `include /etc/nginx/mime.types;`
- `default_type application/octet-stream;`
- `.mjs` 전용 location:
  - `types { application/javascript mjs; }`
  - `default_type application/javascript;`
  - `try_files $uri =404;`

4. `pdf-worker-url.d.ts`
- `pdf.worker.min.mjs?url` 타입 선언 추가

## 재배포 후 확인
1. `docker-compose -f docker-compose.dev.yml build --no-cache`
2. `docker-compose -f docker-compose.dev.yml up -d`
3. Network 확인
- `/assets/pdf.worker.min-*.mjs` -> `200`
- `Content-Type: application/javascript`
4. PDF 진입 시
- fake worker 에러 없음
- `container must be absolutely positioned` 에러 없음
