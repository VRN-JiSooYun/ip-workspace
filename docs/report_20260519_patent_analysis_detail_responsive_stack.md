# Patent Analysis Detail 반응형 Stack Layout 개선

## 요청 요약

특허 분석 상세 페이지도 화면 폭이 모바일 수준으로 줄어들면 PDF 영역과 분석 데이터 영역을 좌우 배열 대신 위/아래 배열로 전환한다.

## 구현 내용

파일: `frontend/src/pages/PatentAnalysisDetail.tsx`

- `1100px` 이하에서 PDF 뷰어 영역과 분석 탭 영역을 세로 stack 레이아웃으로 전환했다.
- 넓은 화면에서는 기존 split 비율 기반 좌우 배치를 유지한다.
- 좁은 화면에서는 PDF 뷰어가 위, 분석 탭이 아래에 표시된다.
- 세로 stack 상태에서는 split 조절 핸들을 숨긴다.
- 세로 stack 상태에서는 페이지 자체가 세로 스크롤되도록 overflow를 조정했다.
- PDF 영역은 작은 화면에서도 뷰어와 PDF 툴바가 보이도록 `min(72vh, 760px)` 높이와 최소 높이를 적용했다.
- 분석 탭 영역은 아래로 내려가며 자체 콘텐츠를 표시할 수 있도록 최소 높이를 보장했다.
- 상세 페이지 상단 제목 영역도 wrap 가능하게 조정해 좁은 화면에서 텍스트와 버튼이 겹치지 않도록 했다.

## UX 동작

- 데스크톱/넓은 화면: PDF와 분석 탭이 기존처럼 좌우로 표시되고 split 핸들로 폭 조절 가능.
- `1100px` 이하: PDF 뷰어가 위에 표시되고 분석 탭이 아래로 이동.
- 작은 화면에서는 split 조작 대신 세로 스크롤로 PDF와 분석 내용을 탐색.
