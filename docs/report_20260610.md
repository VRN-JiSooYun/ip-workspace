## Compound Search API 컨테이너 의존성 오류 수정

- Docker 컨테이너 실행 시 `compound_search/elastic_search_agent.py`가 `analyzer.hier_pattern.AtomCodeWords`를 import하면서 `networkx` 누락으로 실패하는 문제를 확인했습니다.
- `analyzer/hier_pattern.py`는 top-level에서 `networkx`와 `matplotlib`를 import하므로 두 패키지를 `docker/compound-search-api.Dockerfile`의 컨테이너 전용 설치 단계에 추가했습니다.
  - `networkx==3.6.1`
  - `matplotlib==3.10.8`
- `compound_search/requirement.txt`는 수정하지 않았습니다.

## 특허검색 Reference 팝업 Source Type 분기

- compound search `/search` 결과 row에 포함된 `sources/source_list` 데이터를 reference 팝업에 바인딩했습니다.
- 별도 하단 source 섹션 대신 `source_type` 값을 섹션 title로 사용해 Patent API item과 row source item을 source type별로 분기 표시하도록 수정했습니다.
- 좌측 `Source Type` 필터에 Patent API 결과의 source type과 row source의 `source_type`을 함께 표시하고 필터링할 수 있게 했습니다.
- 각 source row에 `source_name`, `source_link`를 표시하고, URL 형태의 `source_link`는 새 탭 링크로 열 수 있게 했습니다. URL이 아닌 `source_link` 값도 텍스트로 표시합니다.
- source row에 `vora_link` 값이 함께 내려오는 경우 `vora_link`도 화면에 표시하고, URL이면 새 탭 링크로 열 수 있게 했습니다.
- row source의 `source_type`이 `patent`인 경우는 row source UX에서 제외하고, `/patents` API 조회 결과만 표시하도록 했습니다.
- source type 원본값이 `substance`인 경우 화면에서는 `Patent`로 표시하도록 정규화했습니다.
- Patent API 결과는 `patent_type` 값이 있더라도 source type 섹션 title을 `Patent`로 고정했습니다.
- source type 섹션 title과 좌측 filter 라벨은 첫 글자가 대문자로 보이도록 정규화했습니다.
- 좌측 `Source Type` 필터가 전체 선택 상태이면 버튼이 `전체 해제`로 바뀌고 클릭 시 모든 선택을 해제하도록 수정했습니다.
- 검색 결과 card/full row 상단의 `...` source link 버튼은 제거했습니다.

## UniversalSearch TypeScript 빌드 오류 수정

- `UniversalSearch.tsx`에서 `CompoundSearchSource` 타입을 사용하면서 import하지 않아 Docker build의 `tsc -b`가 실패하던 문제를 수정했습니다.
- `source_link/vora_link` 배열 필터의 type predicate가 문자열을 반환할 수 있던 조건식을 `value.trim().length > 0` boolean 조건으로 변경했습니다.
