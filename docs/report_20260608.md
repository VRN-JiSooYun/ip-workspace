## SAR Table

### 화합물 영역 핀 고정 레이아웃
- 핀 고정된 화합물 카드에서 별도 흰색 배경, 테두리 강조, 그림자, spacer overlay를 제거했다.
- 핀 고정 시 기존 핀 마크만 표시되도록 유지했다.
- overlap 모드에서 핀 고정 카드도 투명 배경을 유지하도록 조정했다.
- 핀 고정 행 강조 색상을 primary orange 계열에서 blue pinned-state 계열로 변경했다.
- fixed-left table cell에도 동일한 핀 고정 행 색상을 적용했다.

### 핀 고정 카드 선택 상태와 가로 스크롤 겹침
- overlap 값이 `0`일 때 선택된 핀 고정 카드 뒤쪽의 스크롤 카드 텍스트가 비쳐 보이는 문제를 수정했다.

- 선택 outline은 clipped card 내부에서 보이도록 inset을 조정했다.
- overlap 비활성 상태의 선택/hover 핀 고정 카드 배경을 opaque mixed color로 변경했다.

### Quick Viewer 외곽 스타일

## MyBoard

### 그룹/상세 테이블 Shift 범위 선택
- 그룹 테이블과 상세 화합물 테이블에 Shift + row click 범위 선택을 추가했다.
- 범위 선택은 현재 화면에 보이는 테이블 순서를 기준으로 동작한다.
- Ctrl/Cmd + click 기존 toggle 동작을 유지했다.
- Ctrl/Cmd + Shift + click은 현재 선택에 범위를 추가하도록 처리했다.
- context menu row selection과 quick-add selection 시 범위 선택 anchor를 갱신했다.

### 그룹/상세 split 기본 크기
- MyBoard 로드 시 좌/우 split 기본 크기를 divider double-click auto-fit 크기와 동일하게 변경했다.
- divider keyboard reset(`Enter`, `Space`)도 같은 auto-fit 크기를 사용하도록 조정했다.
- group/detail split localStorage 복원을 제거해 페이지 로드 시 항상 auto-fit 크기에서 시작하도록 변경했다.

### 그룹 리스트 컬럼
- 그룹 리스트 컬럼 제목 `그룹 번호`를 `그룹`으로 변경했다.
- 그룹 컬럼 폭을 `72px`에서 `52px`로 줄였다.
- 그룹 리스트 auto-fit split width가 줄어든 fixed-column width를 따르도록 유지했다.
- 그룹 리스트 첫 번째 컬럼으로 `순번`을 추가했다.
- `순번`은 현재 필터/정렬된 `visibleGroupRows` 렌더 순서 기준의 `index + 1`을 표시하고, 셋 자리 comma 규칙을 적용했다.

### 그룹 리스트 핀 고정 버튼
- 별도 핀 고정 컬럼을 삭제하고, 기존 핀 고정 버튼을 화합물 구조 컬럼 좌측 상단으로 이동했다.
- 버튼 클릭 시 행 선택 이벤트가 전파되지 않도록 기존 `stopPropagation` 동작을 유지했다.
- 비활성 핀 버튼은 화합물 구조 영역 hover 시에만 표시하고, 활성 핀 버튼은 상시 표시하도록 조정했다.
- 마우스가 구조 영역 밖으로 이동했을 때 비활성 핀 버튼이 남지 않도록 컬럼 hover와 포커스 기반 표시 조건을 제거했다.
- 핀 고정 버튼 크기를 공통 화합물 구조 액션 버튼과 동일한 `16px` 버튼 박스로 맞췄다.

### Canvas 구조 등록
- Canvas 탭 구조 추가 팝업의 confirm 버튼 이름을 `Preview 생성`에서 `등록`으로 변경했다.
- `RDKit 구조 Preview` 중간 팝업을 제거했다.
- 등록 시 RDKit SVG를 생성해 Fabric canvas에 즉시 삽입하도록 변경했다.
- RDKit rendering 실패 시 ChemDraw SVG를 canvas에 삽입하고 warning message를 표시하도록 했다.

### 숨기기 아이콘
- dev server에서 숨기기 아이콘이 보이지 않는 원인을 normal SVG asset URL을 CSS `mask`에 직접 사용한 문제로 파악했다.
- `eye-off.svg`를 `?raw`로 import하고 기존 `createSvgMaskUrl` helper로 data URL을 만들어 `mask`, `-webkit-mask`에 적용했다.

### Quick Viewer 외곽 스타일

- header/tabs 경계선과 panel/body 배경도 공통 카드 CSS variable 기준으로 맞췄다.

## ChemDraw

### non-passive wheel listener 경고
- ChemDraw Web 내부에서 등록하는 non-passive `wheel` listener 때문에 Chrome console performance violation이 발생하는 원인을 확인했다.
- `installPassiveWheelListenerPatch`를 추가해 `wheel` event listener option에 `passive`가 명시되지 않은 경우 `passive: true`를 부여하도록 했다.
- patch는 ChemDraw Web 사용 경로 주변에만 적용했다.
- frontend build에서 `passiveWheelListenerPatch` module not found 오류가 발생할 수 있어 `frontend/src/utils/passiveWheelListenerPatch.ts` 파일 존재와 import 경로를 재확인했다.
