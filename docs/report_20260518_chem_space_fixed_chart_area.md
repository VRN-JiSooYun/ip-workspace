# Chem Space Fixed Chart Area

## 변경 내용
- Chem Space 페이지의 차트 영역이 화면 폭에 따라 리사이즈되지 않도록 고정 폭을 적용했다.
- 단일 차트/3D 차트 영역은 `1080px` 고정 폭으로 유지한다.
- 3Chart Mode 영역은 `1120px` 고정 폭으로 유지한다.
- 부모 영역이 좁아질 경우 차트를 줄이지 않고 카드 내부에서 가로 스크롤되도록 수정했다.

## 관련 파일
- `frontend/src/pages/ChemSpace.tsx`

## 비고
- 컨트롤 패널과 페이지 레이아웃은 기존 반응형 동작을 유지하고, 차트 렌더링 영역만 고정형으로 변경했다.
